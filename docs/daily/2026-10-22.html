摘要总结
论文研究昇腾 NPU 上的训练效率问题：现有框架级编译优化（如算子融合）只被部分应用，留下碎片化计算和可避免的执行开销，而 profiling 引导的调优通常依赖高成本试错。为此提出 TrainBridge——一种把成熟 GPU 编译栈产出的高度优化执行当作任务特定参考、从中抽取优化意图（optimization intents）来指导 NPU 程序重写，再通过迭代 profiling 精化重写程序的智能体式方法。在覆盖 LLM 预训练、图像分类与视觉-语言训练的四个迁移负载上平均加速 1.7 倍，在 27 个 Modded-NanoGPT speedrun 记录上平均加速接近 2.0 倍。
核心创新点
  • 以 GPU 编译栈产生的高度优化执行作为 NPU 调优的任务特定参考证据，替代通用启发式规则，把跨栈迁移转成有据可依的重写决策
  • 设计了从 GPU 训练执行中自动抽取 optimization intents 并映射为 NPU 程序重写动作的机制
  • 在程序重写后接入迭代 profiling 闭环精化，专门弥补框架级算子融合仅部分生效导致的碎片化计算
  • 在 4 个跨 LLM 预训练/图像分类/视觉-语言训练负载上实测平均 1.7x、27 个 Modded-NanoGPT speedrun 记录上近 2.0x 加速
解决的问题 / 适用场景
面向已有可运行 GPU 参考实现、希望迁移到昇腾 NPU 并逼近原性能的训练任务，尤其是缺少专职调优人力的 LLM 预训练与多模态训练流水线。适用于训练框架和集群侧的性能工程，用来降低手工 profiling 试错的成本。

摘要总结

核心创新点
  • 将梯度冲突处理解耦为“受保护目标的选择”和“触发投影的条件”两个独立决策，并用最近点公式给出闭式更新，只在每个 optimizer mini-batch 合成一次梯度，不改变原有训练目标。
  • 在优化器变换之前刻画投影对受保护目标的一阶效应，从而可分析投影后蒸馏目标及其混合权重为何仍然显著影响结果。
  • 提出梯度诊断方法，把智能体训练中的梯度冲突量化为“丢掉的局部优化进度”，为是否需要选择性纠正提供判据。
  • 实验发现保护方向与投影门控必须联合选取：在 ALFWorld 三种联合训练配方上成功率提升 1.5–15.9 个百分点，WebShop 上 SDAR 由 60.7% 提升到 64.6%。
解决的问题 / 适用场景
用于需要同时利用任务 reward 和教师模型稠密监督来训练 LLM 智能体的强化学习管线，解决两目标梯度相互抵消导致训练低效、收敛变慢的问题；适用于自蒸馏式 agent 后训练与对齐系统。

HGM-Dual: Lineage-Aware Guided Agent Harness Optimization for Long-Horizon Planning
HGM-Dual：面向长程规划的谱系感知引导式智能体 Harness 优化
未明确披露
点击收起
摘要总结
论文指出 DGM、HGM 这类递归自我改进的 harness（提示、工具、工作流）优化方法主要在编码任务上发展，因为“改进智能体的能力”与“被改进的能力”天然重合；而长程规划任务要求智能体产出同时满足多个交互约束的工具调用序列，这种对齐被打破，开放式自我修改会反复探索无效改动并大量消耗评测预算。为此提出 HGM-Dual：一方面把智能体演化表示为谱系感知上下文（lineage-aware context），记录每个祖先节点改了什么、哪些行为提升或退化、哪些修改无效，使编辑器获得显式的“改动—结果”归因而非无结构的历史档案；另一方面引入错误条件双路子代生成，对每个被选父代同时生成一个保持开放探索的通用子代和若干专门针对该父代最高排名约束违反所对应 harness 组件的专用子代。在规划基准上相较最强基线最高取得 14.45% 的 case accuracy 相对提升，并以 2 倍到 4 倍更少的评测预算达到 HGM 各变体的最终性能。
核心创新点
  • 谱系感知上下文（lineage-aware context）：把演化历史结构化为“祖先改动了哪个 harness 组件、对应行为是提升还是退化、哪些修改无效”的可归因记录，替代 DGM/HGM 使用的无结构 agent 档案。
  • 错误条件双路子代生成（error-conditioned dual-path child generation）：每个父代同时派出一个通用子代用于开放式探索，以及若干聚焦父代最高排名约束违反相关组件的专用子代。
  • 面向规划任务的诊断式 harness 演化框架，针对“自我改进能力与被改进能力一致”这一编码场景假设在长程约束规划中失效的根因进行修正。
  • 预算效率结果：case accuracy 相对最强基线最高提升 14.45%，同时以 2x–4x 更少的评测预算追平 HGM 变体的最终性能。
解决的问题 / 适用场景
用于基于冻结或闭源 LLM 搭建、需要多步工具调用并同时满足多项交互约束的长程规划智能体的自动 harness 迭代，解决开放式自我修改反复试错、评测预算被大量浪费的问题；适用于受限模型权限下的 agent 平台自动化调优与规划类任务系统。

未明确披露

摘要总结
LiveAct 研究多智能体视频世界模型：由单一模型为多个受控智能体联合生成未来视觉画面，同时解析从二值游戏按键到连续机器人指令的异构控制信号。其核心是异构动作接口 HAI，包含两部分：Agent-Aware Spatial Modulation 通过语言驱动的空间门控与智能体专属注意力，把每条动作流绑定到它应对应的视觉实体；Schema-Guided Action Adaptation 用自然语言描述每个控制变量的语义，并将语义 token 与同步数值共同调制，从而解决同一张量维度在不同任务中分别表示攻击、转向或机器人指令的问题。作者进一步用 teacher forcing 与 rollout-aware distribution matching 把整套接口迁移到分块因果生成器，在保留智能体专属控制的同时实现流式生成。在覆盖游戏与多机器人操作的六个多智能体数据源上，LiveAct 在不提供智能体位置与身份裁剪的条件下取得 0.898（游戏）与 0.942（机器人操作）的智能体归属准确率，因果生成器在 512×448 分辨率下达到 17.70 FPS。
核心创新点
  • 提出异构动作接口 HAI，用同一模型统一解析二值游戏按键与连续机器人指令两类控制信号，跨任务共享控制语义
  • Agent-Aware Spatial Modulation：以语言驱动的空间门控加上智能体专属注意力，把动作流绑定到目标视觉实体，且不依赖智能体位置标注和身份裁剪
  • Schema-Guided Action Adaptation：为每个控制变量生成语言描述，并用同步数值调制其语义 token，使同一张量维度可在不同任务中承载不同含义
  • 通过 teacher forcing 与 rollout-aware distribution matching 将接口迁移到分块因果生成器，实现 512×448 下 17.70 FPS 的实时流式生成
解决的问题 / 适用场景
适用于需要多角色并行控制的交互式内容生成与仿真，例如游戏引擎中多玩家/多 NPC 的实时画面预测，以及多机器人操作任务的策略预演与训练环境构建。

点击收起
摘要总结
论文研究低比特量化大模型在长程推理上的能力退化，指出既有 QAT 做法用全精度模型在固定回复序列上监督量化学生模型存在两个问题：训练前缀与学生自生成前缀不匹配且随回复变长而加剧；学生在自己的前缀上对下一 token 候选存在系统性低估与高估，且在高熵前缀处更严重。作者提出 OnQ 低比特恢复流水线，先做分块校准，再让学生模型自行生成回复并在自身前缀上接受全精度教师监督（on-policy 蒸馏），同时引入按候选 teacher-student 概率比加权前向/反向 KL 的 Dynamic KL，以同时纠正低估与高估。在 Qwen3-1.7B/4B/8B 的 2-bit 与 3-bit 设置下，OnQ 取得九基准平均最高分，长程推理基准提升最大；2-bit 时在每个模型规模、每个基准上都超过所有基线，Qwen3-8B 平均分比最强基线高 10.26 分，且回复更短、截断与重复错误更少。
核心创新点
  • 识别出固定回复监督的两个具体失配：训练前缀与学生自生成前缀随回复变长而发散，以及学生在自己前缀上对下一 token 候选的低估/高估在高熵前缀处更频繁
  • 提出 OnQ 流水线，把分块校准与 on-policy 蒸馏结合，让量化学生模型在自身生成的前缀上接受全精度教师监督
  • 提出候选级 Dynamic KL：按每个候选的 teacher-student 概率比在前向 KL 与反向 KL 之间加权，平衡对低估与高估的纠正
  • 在 Qwen3-1.7B/4B/8B 的 2-bit 和 3-bit 上取得九基准最高平均分；2-bit 下全模型规模全基准超越基线，Qwen3-8B 平均提升 10.26 分，并减少截断与重复错误、缩短回复长度

核心创新点
  • 将探测簇字节区间到对象存储请求的分组问题形式化为每查询全局优化问题，并给出满足每查询请求上限、最小化并发感知延迟代理的最优合并计划
  • 提出基于优化动态规划与自适应前沿搜索的求解算法，可在 10ms 以内返回 (1+ε) 近似最优计划，适配不同数据集与查询负载而无需人工 gap/span 阈值
  • 设计轻量离线重排序 pass，在不改变 ANN 搜索语义的前提下提高请求可合并性
  • 在 Lance I/O 调度器中实现并于 AWS S3 上以七个数据集的 IVFPQ 索引（含 1 亿规模的 SIFT100M、DEEP100M）验证，QPS 提升 1.09–3.48 倍、GET 减少 2.12–5.19 倍且召回不变

Second Thoughts: Exploring and Planning through Comparative Imagination in World Models
再三思：在世界模型中通过比较性想象进行探索与规划
未明确披露
点击收起
摘要总结
论文研究在世界模型中「应该想象并比较哪些备选动作序列」以及「候选计划何时应替换已学策略」这两个耦合决策，提出 SDI（Sibling Disagreement in Imagination）：以同一模型状态下对 actor 自身动作序列的重复 rollout 作为共享参照，度量固定行为下的变化幅度。该参照同时驱动两个量——候选回报的离散程度（探索信号）与候选计划的预测优势（动作接受门控）：当计划优势超过参照变异性的固定倍数时执行计划动作，否则退回 actor 策略；方法复用基座智能体的 world model、actor 与 critic，无需额外的分歧集成。在 Meta-World、Adroit、DM-Control 上，SDI 在三个套件的任务平均分均高于所有对比基线，18 个任务中有 15 个达到或超过最强基线；同一模拟器状态下的配对评测显示门控相比无门控规划能同时改善 actor 失败后的恢复与成功行为的保持，并显著降低回报退化。
