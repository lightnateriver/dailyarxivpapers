摘要总结
论文针对基于大语言模型的社会仿真中智能体既不可解释、也无法定向操控这两大缺陷，在同一实验框架下系统比较了三类干预方法：基于提示词的操纵、基于稀疏自编码器（SAE）提取特征的操控，以及基于探针（probe）方向向量的操控。作者把人类行为拆解为偏好（风险态度、利他性）与能力（发散性创造力、产品创新）两个基础成分，并用四个经典经济学与创造力任务以自然语言交互形式加以操作化。整体实验表明，SAE 与 probe 方法在社会仿真中通常优于基础提示词方法，但这一优势大小取决于所采用的具体提示策略；两者可串联为「SAE 把智能体内部表示拆成人类可读特征、probe 再沿指定方向稳定推动行为」的有效流程。
核心创新点
  • 提出将 SAE 特征分解与探针方向操控组合成可复用流程：先用 SAE 把智能体内部表示拆分为人类可读特征，再用 probe 可靠地朝指定方向改变智能体行为，从而同时获得可解释性与可操控性。
  • 在同一实验框架下横向对比 prompt 操纵、SAE 特征操控、probe 方向操控三类方法对 LLM 社会仿真智能体的效果，并发现 SAE/probe 的优势并非无条件，而是依赖于具体采用的提示策略。
  • 将风险态度、利他性、发散性创造力与产品创新四类人类行为基础成分操作化为四个经典经济学/创造力自然语言任务，为社科仿真提供可复现的评测载体。
  • 论证 SAE 与 probe 的互补性：SAE 负责机制归因式的特征分解，probe 负责行为层面的定向调节，二者结合使社科研究者能在仿真中放大或抑制特定理论机制。
解决的问题 / 适用场景
面向社会科学研究者，解决 LLM 智能体仿真结果「机制看不清、行为调不动」的问题，适用于经济行为模拟、创造力实验、政策与社会现象推演等需要可解释机制归因并定向放大/抑制特定行为机制的社科仿真系统。

核心创新点
  • 提出走廊条件（corridor-conditioned）的候选轨迹专属风险建模：每个候选轨迹通过 footprint-aware 几何与 agent-corridor 表示去查询共享的演化环境，解决了“同一智能体运动对不同自车轨迹风险不同”这一被忽视的问题。

  • 给出双条件化框架：corpus-conditional 给出语料级平均表示演化，context-conditional 给出特定上下文的期望几何，二者之差被形式化为 mean-field deviation，成为任务无关的上下文特定计算度量。

  • 提出 coder 与 critic 在同一批执行 rollout 上联合更新的训练框架，把评审角色从提示式调用变为经执行结果校准的可训练组件
  • 评判器不仅输出通过/失败预测，还给出简短诊断反馈，将单一 pass/fail 位扩展为可用于细粒度信用分配的监督信号
  • 设计一致性门控机制：只有当评判器与执行器对当前 rollout 组的判断一致时，代码模型才使用评判器信号，从而抑制错误信号传播
  • 在八个代码基准、两个开源骨干上同时对比无 critic 的 GRPO、提示式 reviewer 系统与标量奖励模型基线，并报告了策略梯度步数与沙箱执行次数的降低
  • 通过消融和可靠性分析将性能提升归因于信用分配改善而非采样预算扩大
解决的问题 / 适用场景
适用于需要可靠执行反馈的代码大模型后训练与线上代码助手场景，例如在沙箱成本或采样预算受限时提升程序通过率，并减少对测试执行次数的依赖。
