置信度推理图：面向LLM智能体的结构化置信度估计

摘要总结
论文针对在关键领域使用 LLM 智能体时、判断是否信任其输出或进行人工干预需要校准置信度，而成功证据分散在异构且相互依赖的轨迹步骤中，且实际部署还面临前沿模型内部信号不可得、agent rollout 成本高、训练数据可能缺失或迅速过时等困难，提出置信度推理图（Confidence Reasoning Graphs, CRG）。CRG 是一种推理时框架，无需特权模型内部访问或训练数据，仅从单条轨迹估计智能体成功完成任务的概率：它以“智能体完成了任务”为主张，将其分解为基于轨迹证据的上下文子主张，对每个终止主张估计置信度，再聚合为整体置信度。在3个 agentic benchmark、3个 backbone 模型与3个 agent 框架上的实验表明，CRG 相比 verbalized、sampling-based 与 white-box surrogate 基线能给出更好校准的置信度与更强的风险感知决策，并揭示仅看校准误差可能产生误导（white-box surrogate 基线看似校准良好但判别力接近随机）；消融显示其增益主要来自主张级置信度估计与聚合而非图结构构建本身。CRG 还会暴露每个置信度估计背后的主张与轨迹证据，从而支持决策时审计。
核心创新点
  • 提出推理时置信度估计框架 CRG：仅凭单条轨迹、无需特权模型访问或训练数据，即可估计智能体任务成功概率
  • 将整体判断分解为以轨迹证据为基础的上下文子主张，对终止主张逐一估计置信度再聚合，消融证明增益来自 claim-level 估计与聚合而非图构建本身
  • 在3个 agentic benchmark × 3个 backbone × 3个 agent 框架上系统验证，较 verbalized、sampling-based 与 white-box surrogate 基线校准更优、风险感知决策更强
  • 发现仅凭校准误差评估会误导（white-box surrogate 看似校准良好、判别力却接近随机），并让 CRG 输出可审计的主张与轨迹证据供决策时检查
解决的问题 / 适用场景
面向高风险关键领域的 LLM 智能体部署，用于在智能体执行过程中判断其输出是否可信、是否需要人工介入或拒答，适用于需要校准置信度与风险感知决策的自动化代理、运维/金融/医疗等高风险业务流程以及智能体监控与审计环节。
