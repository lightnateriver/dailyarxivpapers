摘要总结
多模态检索增强生成（mRAG）中，多智能体系统通过智能体间通信能取得优于单模型的集体智能，但代价是高昂的 token 开销与计算成本。为此本文提出 M3Prune，一种多模态多智能体层级通信图剪枝框架：先在文本与视觉模态内部做图稀疏化，保留任务关键通信边；再构建跨模态通信图，并用模态对齐分数剪枝冗余的跨模态连接、鼓励一致的跨模态推理；最后渐进式剪除冗余边，得到高效的层级拓扑结构。在通用与领域专用 mRAG 基准上，M3Prune 均优于单智能体及强多智能体 mRAG 系统，同时显著提升 token 效率。
核心创新点
  • 提出模态内（intra-modal）图稀疏化：分别在文本与视觉模态中识别任务关键的通信链路，剪除冗余边。
  • 设计模态间（inter-modal）通信图剪枝：结合模态对齐分数（modality alignment score）稀疏化跨模态连接，引导一致性跨模态推理。
  • 渐进式层级剪枝：从模态内到模态间逐级剪除冗余边，得到高效的层级通信拓扑，兼顾性能与 token 开销。

摘要总结
APQF 是一个基于智能体的自动化模型压缩框架，将结构化剪枝、混合精度量化感知训练与精度恢复整合为一条完整流水线。profiling agent 先测量模型各层的计算成本分布与剪枝敏感度，再由 LLM planner 据此提出逐层剪枝比例、逐层位宽和恢复策略，并在执行前验证。在 ImageNet-1k 上 APQF 将计算量（bit-operations）降至原来的 5.6%-7.7%（约 13-18 倍压缩），同时精度接近基线；在 20 万张图像预算下 Top-1 比现有联合剪枝+量化方法高约 17 个百分点。消融实验表明，相同计算量下均匀压缩的精度损失最大。
核心创新点
  • 首次将 LLM 引导、profiling 数据驱动的决策与完全训练感知的剪枝+量化流水线结合，同时适用于 CNN 与视觉 Transformer

  • 引入自适应微调（adaptive fine-tuning）实现精度恢复，与训练感知的混合精度量化感知训练协同
  • VGG7 上仅用基线 0.41% 的 bit-operations 即达 93.15% 精度，是该压缩水平下唯一优于全精度基线的方案

解决现有剪枝与量化依赖人工专家选择、难以跨架构推广、且统一压缩设置忽视不同层对压缩的差异化响应而导致精度损失的问题，为资源受限的边缘设备提供自动化、高精度的模型压缩方案。

摘要总结
可验证奖励强化学习在长程、多轮 agentic 任务中常难以将稀疏的结果奖励归因到少数决定性决策上；现有特权自蒸馏方法提供了更稠密的监督，但并未解决局部信号如何表征时序信用的问题。AgentOPSD 提出一种免 critic 的递归 turn 级信用分配方法：将 token 级 teacher-student log-probability 差距聚合成 turn 级证据，并在 log-odds 空间递归更新贝叶斯信念状态，从而把稀疏的结果监督转化为原则化的 turn 级信用信号。该方法与标准策略优化完全兼容，既不需要额外的 critic 也不需要额外 rollout。在 ALFWorld、WebShop 和 Search-QA 上使用 Qwen2.5 3B/7B 评估，AgentOPSD 全面超越 GRPO 和强自蒸馏基线，在 ALFWorld 上配合 Qwen2.5-7B 达到 89.1% 的成功率。

  • 通过相邻信念状态间的边际信念修正（marginal belief revision）识别决定性 turn（pivotal turns），精确指认影响最终结果的关键决策
  • 与标准策略优化完全兼容，无需额外 critic 或额外 rollout，实现成本低、集成简单
解决的问题 / 适用场景
解决长程多轮 agentic 推理/交互任务中信用分配困难的问题：当稀疏的最终结果奖励无法反映中途哪个决策真正决定成败时（如 ALFWorld 具身任务、WebShop 购物、Search-QA 搜索问答），为策略优化提供 turn 级的稠密信用信号以提升训练效果。

摘要总结
本文针对在线策略自蒸馏（OPSD）在推理模型强化学习中的信号稀疏问题提出改进。OPSD 通过查询特权教师模型在学生的各前缀位置提供密集的 token 级分布监督，但作者发现标准 OPSD 未充分利用 rollout 的时间结构：它对每个位置的局部散度（divergence）赋予相同权重，忽略了相同散度可能源于不同教师-学生分歧历史这一时序差异。为此提出的 DASH 方法将每个局部蒸馏信号与序列级均值的差距映射为自适应传播门控，并用其控制反向多步聚合，从而根据生成过程中局部散度的演变动态调整 token 级监督权重。在三个数学推理基准、三个模型规模上的实验显示，DASH 在所有基准和规模上均优于匹配的 vanilla OPSD 复跑，且不增加任何额外的教师或学生前向计算。

  • 复用 OPSD 已计算的教师/学生分布，收益零额外前向开销
