摘要总结

核心创新点
  • 提出空地场景图 AGSG 作为类型化中间表示，统一表达智能体、空中任务、事件、通信链路、成功条件及跨域依赖
  • 将自然语言到空地协同仿真场景的生成重构为“编译即验证”流程，集成执行前可行性检查与基于轨迹的运行时验证
  • 给出失败定位与有界修复机制，可仅局部重写违规片段而不重新生成整场景
  • 发布 AURORA-Bench，用“是否忠实实现请求的时空/通信/行为关系”取代单纯的执行完成度指标，并揭示 completion 评测漏掉的静默失败

面向城市空中交通、无人机配送与车路空协同等仿真验证场景，帮助研究人员和工程团队用自然语言快速构造可校验、可定位问题的交通仿真算例，避免因场景看似成功执行而得到不可信结论。

摘要总结
论文研究 agent harness 的三个组成部分（规划引导、执行组织、完成校验）对成功率、错误接受率与成本的影响，实验基于 τ²-bench 的两个 Retail 任务和一个 Airline 试点。核心对照设计是将预先写好的任务专属计划（Fixed）与词数匹配但被打乱的策略文本（Sham）配对，从而剥离出“引导内容”本身的贡献；在 265 个匹配单元上，Fixed 使 oracle 验证成功率提升 7.17 个百分点（90% 任务聚类 bootstrap 区间 1.15–13.36），增益集中在高复杂度任务。另有一个只读终端校验器可拒掉 61% 的 Retail oracle 无效轨迹，同时误拒 17% 的正确轨迹，每 episode 额外成本不足 1 美分；作者还发现哪个组件更重要取决于错误接受所对应的责任/损失定价：低责任时规划增益占优，高责任时校验器避免的假通过占优，且单独使用校验器就能以极低成本获得完整“规划+校验”栈的大部分假通过收益。
核心创新点
  • 在 τ²-bench 上提出 Fixed（任务专属预写计划）对照 Sham（词数匹配的打乱策略文本）的配对实验设计，在 265 个匹配单元中把规划引导内容的因果贡献量化为 +7.17 个百分点成功率
  • 给出只读终端校验器的实测特性：拒掉 61% 的 Retail oracle 无效轨迹、误拒 17% 正确轨迹，单 episode 额外成本低于 1 美分
  • 提出以“错误接受的责任/损失定价”为轴的分析框架：低责任时规划增益主导，高责任时校验器避免的假通过收益主导
  • 证明独立校验器即可捕获完整规划+校验栈近全部的假通过收益，且成本仅为其一小部分，说明组件价值取决于部署方的风险定价
解决的问题 / 适用场景
为构建与选型 LLM 智能体执行框架（harness）的团队提供依据：在客服/工单办理等有状态业务流程中，决定该把预算投在任务专属规划提示上还是投在独立完成性校验（verifier）上，并据此按业务对错误受理的风险定价控制成本与假通过率。

适用于训练需要与外部环境多轮交互、却只能拿到轨迹级成败反馈的智能体，如家居指令执行（ALFWorld）与网购决策（WebShop）；可迁移到任何基于 Qwen 类底座的多轮工具/交互式 Agent 训练流水线，降低对稠密奖励设计或人工标注的依赖。

摘要总结

  • 分层纠错机制：由图世界模型直接推导的修正就地修复，只有需要语义推理的错误才触发 LLM 重新规划，减少昂贵的模型调用并提升恢复能力。
  • 面向多任务指令的分布信念推理：在物体可能位置的分布上重排剩余子任务以最小化期望搜索代价，相比静态版本移动距离降低约 5.4%。
  • 在 BEHAVIOR-1K 上给出大跨度量化收益：Qwen3-8B 下单任务成功率 41.2%→91.8%、多任务 19.9%→92.6%，且对紧凑模型与前沿托管 LLM 均成立。

适用于家庭服务机器人、仓储与实验室自动化等需要执行长程多步操作指令的具身智能系统，解决规划不可靠、失败后无法自行恢复以及在物体位置未知时搜索效率低下的问题。

  • 提出基于扰动的位置响应 R(Δ, t_denoise) 敏感度度量，揭示上下文影响随时间距离陡降且随去噪步系统性变化
