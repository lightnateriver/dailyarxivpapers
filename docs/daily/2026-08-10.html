摘要总结
论文提出 Agent Memory Distillation (AMD)，一个免训练的框架，通过层级化记忆把大型教师智能体的结构化知识迁移给小型学生智能体。AMD 从教师成功轨迹中构建三种互补记忆：工作流记忆编码任务级策略、子任务记忆提供中间粒度的具体行为示例、函数记忆捕获逐函数调用约定与常见陷阱；前两者在任务开始时主动注入，函数记忆则在工具调用出错时被动检索。在 AppWorld、BFCL V3、ToolSandbox 三个工具使用基准上，以 GPT-5-mini 为教师、4 个 4B-8B 学生模型评测，平均准确率分别提升 27.2、11.2、3.4 个百分点，且一致优于现有基于记忆的基线。分析还表明子任务记忆贡献最大，4B 规模学生获益最多。
核心创新点
  • 提出免训练的层级记忆蒸馏框架，无需微调即可将大教师智能体的经验迁移给小模型
  • 设计工作流/子任务/函数三种互补粒度的记忆，覆盖任务策略、行为示例与调用约定
  • 混合注入机制：主动注入任务级记忆 + 出错时被动检索函数级记忆，兼顾效率与针对性
  • 系统剖析各记忆类型的贡献、教师有效性条件（教师能力与学生兼容性）及受益规模规律
解决的问题 / 适用场景
解决小语言模型因自身难以生成足够成功轨迹而无法有效利用记忆系统的问题，适用于工具调用、API 使用等智能体场景；让 4B-8B 小模型在不做训练的情况下获得接近大模型的工具使用能力。

摘要总结
符号执行旨在探索程序中的可行路径，但一次有界运行往往资源耗尽时仍有大量程序行为未被覆盖。本文提出另一种思路：不改变底层符号执行器内部的状态探索机制，而是在多次有界符号执行（BSE）运行之间进行推理，用上一次运行的证据来选择并配置下一次运行。作者构建了 Agolic 系统，其中 LLM 智能体基于源码、重放覆盖率与历史定向尝试记录进行规划，在若干 C/C++ 程序上显著扩展了分支覆盖率。
核心创新点
  • 提出智能体规划层与底层符号执行器解耦的架构，让规划智能体只负责跨运行的选择与配置，不干预普通状态探索
  • 利用 LLM 智能体结合源码、重放的覆盖率和历史定向尝试证据来指导后续有界运行的参数与目标选择
  • 采用可适配设计，规划智能体、可用证据与执行模式均可针对不同符号执行工具和分析目标替换
  • 实验显示分支覆盖率平均提升 3 倍以上，且能覆盖覆盖率引导模糊测试与基于编译器的混合执行语料库均未触及的分支
解决的问题 / 适用场景
解决符号执行单次有界运行资源有限、覆盖率难以提升的问题，适用于程序漏洞挖掘、分支覆盖探索、模糊测试与符号执行工具结合等代码分析场景。
