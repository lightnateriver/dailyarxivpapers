摘要总结
论文针对昇腾 NPU 上 AscendC 自定义算子开发慢、依赖专家且难以自动化，而现有 AI Agent 虽在 GPU kernel 基准上接近专家、却因相关训练数据稀缺而难以生成 AscendC 内核的问题，提出 CANN 原生系统 CAKE。CAKE 组合了自适应多 DSL 路由、相互分离的 Generation 与 Evolution 两种模式，以及经由 CAKE Book 与 Self-Evolving Agent 实现的「经审核知识复用」。在 Ascend 950PR 上的 CANN-Bench v1.1 的 53 个算子中，标准集 1060/1060 全部通过、隐藏集 4167/4240（98.28%）通过，总分均值 78.63/100，相对基线平均加速 1.334 倍。Evolution 模式进一步优化已正确的算子：EngramGateFusion 在 20 轮内把聚合 device time 降低 46.6%，roofline 差距均值约减半。
核心创新点
  • 自适应多 DSL 路由：按算子特征选择生成路径，绕开 AscendC 训练数据稀缺造成的单一路径生成能力不足
  • Generation 与 Evolution 模式分离：先保证算子正确性，再在正确性约束下持续演化性能，EngramGateFusion 20 轮内 device time 降 46.6%、roofline gap 近半
  • CAKE Book 加 Self-Evolving Agent 的经审核知识复用机制，把已验证的算子经验沉淀复用，形成自我演化的闭环
  • 在 CANN-Bench v1.1（53 个算子，Ascend 950PR）上标准集 100% 通过、隐藏集 98.28%，平均 1.334 倍加速，是面向昇腾的可部署自定义算子系统级方案
解决的问题 / 适用场景
用于在昇腾 NPU 上自动产出可直接部署的高性能自定义算子，替代人工 AscendC 开发；适用于需要在 PyTorch/CANN 栈中快速补齐融合算子、注意力变体等缺失算子的训练与推理加速场景。

摘要总结

  • 提出 SWE-Verifier：一个轻量生成式验证器，对编码智能体提议的动作打分以决定是否触发额外候选采样，并对候选动作排序后再执行，把“采样—验证”从每步都做变为按需触发。

  • 实验发现仅在不足 4% 的步骤上触发验证，即可达到或超过“按整条轨迹验证”和“每步都验证”两类基线的解决率，且成本显著更低，说明选择性验证与轻量验证器收益互补。

解决编码智能体因盲目多路采样与逐步验证导致 API 成本与推理延迟过高、且错误动作会把智能体带入低价值状态的问题。适用于仓库级缺陷修复类 SWE 智能体（如基于 mini-swe-agent 的 harness）在生产流水线中的降本部署，包括工单自动修复与 CI 中的自动改码环节。

未明确披露
点击收起
摘要总结
论文面向给定初始与终端构型、需满足智能体间避碰与障碍约束的实时多智能体路径规划问题，将其建模为高维最优控制问题，指出基于 Hamilton-Jacobi-Bellman 方程或庞特里亚金最大值原理（PMP）的经典解法会随智能体数量增长而因维数灾难和交互约束带来的非凸性变得不可解。作者提出 OCFormer：用 Transformer 参数化一个坐标变换的逆映射，把在解耦哈密顿量下各智能体独立演化的可解析潜空间映射回存在耦合交互的物理空间，并以包含 PMP 哈密顿 ODE 残差项与边界匹配项的物理信息损失训练，无需预计算轨迹数据；自注意力机制使模型天然具备对智能体的置换等变性，这是既有辛网络方法未显式保证的结构对称性。在边界条件分布上训练后，摊销式 OCFormer 可在单次前向（约 220ms）内为未见过的初始/终端构型生成近最优轨迹，实现无需重训的实时推理；作者还给出基于 L-BFGS 微调的轻量迁移学习框架，数秒内即可适配分布外扰动。在 2D 与 3D 多智能体导航、最多 128 个智能体的实验中验证了可扩展性与效率。
核心创新点
  • OCFormer 用 Transformer 参数化「解耦潜空间→耦合物理空间」坐标变换的逆映射，将高维耦合最优控制求解转化为一次网络前向，规避了 HJB/PMP 求解的维数灾难
  • 采用纯物理信息损失训练：PMP 哈密顿 ODE 残差 + 边界匹配项，完全不需要预先计算的专家轨迹数据
  • 借助自注意力显式获得对智能体的置换等变性（permutation equivariance），弥补了辛网络（symplectic network）类方法不原生保证该对称性的缺陷
  • 提出基于 L-BFGS 微调的轻量迁移框架，可在秒级把预训练模型适配到分布外扰动场景，配合约 220ms 的单次前向实现实时推理
  • 在 2D/3D 多智能体导航任务上扩展到最多 128 个智能体，验证了精度与可扩展性
解决的问题 / 适用场景
适用于需要在线、可重规划的集群运动规划系统，例如无人机/移动机器人编队的实时队形变换与避障、仓储多 AGV 协同调度，以及仿真环境中的大规模智能体轨迹快速生成；尤其适合边界条件频繁变化、无法每次重新求解最优控制问题的场景。

摘要总结
论文研究提示注入（prompt injection）下大语言模型智能体调用工具的安全执行问题，用 Petri 网把 LLM 与其工具之间的执行护栏形式化为监督控制问题：托肯（mark）表示能力、审批与预算，迁移只有在所需托肯齐备时才能触发，因此前置条件不满足或额度已耗尽的注入请求无论措辞如何都会被拒绝。作者将工具执行结果视为不可控事件，用经典的极大允许（maximally permissive）监督器保证安全，并给出该安全性在四条假设下可传递到运行系统的结论。为刻画智能体被拒后仍可能重新提案的行为，论文引入「重规划闭环」（replanning closed loop）概念，其中每次重试都消耗一次推理调用，并证明在该闭环中经典监督器的侵入性可能任意大于一个更严格的安全监督器；进而对给定提案模型，把极大允许且最小侵入的监督器刻画为经典监督器的「价值阈值精化」，在明确条件下该精化对两个并发动作的排序最多只多用一个监视库所（monitor place）。在自主发布（autonomous release）智能体案例上，综合（synthesis）结果表明安全部署需要监督器能在 rollout 开始后拒绝的步骤。
核心创新点
  • 用 Petri 网的托肯（能力/审批/预算）把 LLM 与工具之间的执行护栏形式化为监督控制问题，使注入请求在前置条件不满足或预算已耗尽时被结构性拒绝，而非依赖措辞过滤
  • 将工具执行结果建模为不可控事件，用极大允许监督器保障安全，并证明在四条假设下安全性可传递到实际运行系统
  • 提出「重规划闭环」概念（每次重试计一次推理调用），证明经典监督器在此闭环中侵入性可任意大于更严格的安全监督器
  • 对给定提案模型刻画极大允许且最小侵入监督器为经典监督器的价值阈值精化，并证明在特定条件下该精化对并发动作的排序最多只额外占用一个 monitor place
  • 在自主发布智能体上通过综合给出结论：安全部署要求监督器具备在一次 rollout 已开始后仍可拒绝某一步的能力
解决的问题 / 适用场景
适用于把 LLM 智能体接入真实工具与外部系统的部署场景，例如代码发布/上线流水线、企业自动化运维与工单系统、需审批与预算上限的 API 调用代理，用于在提示注入攻击下阻断越权或重复耗额的工具调用，同时尽量少打断合法任务流程。

Direct Pass@$k$ Optimization for Thought Pruning: Balancing Quality and Diversity in Test-Time Reasoning

未明确披露
点击收起
摘要总结
测试时扩展让推理模型大量采样候选解，以期至少命中一个正确答案，但把每个候选都完整求解的代价高昂；现有做法是只生成较短的前缀，就裁剪候选池，其中质量型方法按得分淘汰、多样性型方法按轨迹差异保留，这本质上是探索与利用的权衡，却几乎没有工作直接优化它。作者提出直接以 pass@$k$ 为目标的剪枝流程：在给定保留数量下，选择这样的子集——使“池中至少一个部分解续写后能得到正确答案”的概率最大；由此让质量与多样性由同一准则自然平衡，而不依赖额外的启发式设计。在八个开源权重推理模型上，该方法优于现有的质量型与多样性型剪枝策略；当剪枝后保留中等数量的部分解继续生成时，增益最为明显。
核心创新点
  • 把思维剪枝显式建模为对候选池的 pass@$k$ 最大化：按“至少一个部分解续写后正确”的概率挑选子集，让质量与多样性在同一目标内同时优化，而不是靠分开的启发式规则拼接。
  • 剪枝准则自身就会惩罚冗余：高质量的部分解被奖励，彼此重复的推理轨迹被抑制，无需额外设计多样性惩罚项或聚类步骤。
  • 在八个开源权重推理模型上系统对比质量型与多样性型剪枝基线并取得更优结果，同时发现保留中等规模的候选池（而不是保留得极少或极多）时收益最大。
解决的问题 / 适用场景
适用于需要“大量采样再筛选”的推理模型部署，例如数学与逻辑题求解、代码生成的测试时扩展：先用较短的前缀淘汰大部分候选，只对少数部分解继续生成，从而在同等算力和显存预算下提高至少命中一个正确答案的概率。

Edit, Don't Imitate: Minimal-Edit On-Policy Distillation for Multimodal Reasoning
编辑而非模仿：面向多模态推理的最小编辑同策略蒸馏
未明确披露
点击收起
摘要总结
视觉数学推理常常在推理开始前就已经失败：视觉语言模型误读图形后，后续推理便建立在错误前提上；这种感知瓶颈在小模型上尤其突出，而准确的文本图形描述能显著缩小它和大模型之间的差距，可是要在推理时获得这类描述，就需要额外标注或模型调用。作者提出最小编辑纠正式同策略蒸馏（minimal-edit corrective on-policy distillation）：训练阶段只把参考图形描述和已验证的参考解作为训练期信息；教师按最小编辑目标给学生的错误 rollout 打分，只有教师不认可的 token 才计入纠正损失；正确的 rollout 则用任务奖励做强化学习。该方法保留了同策略监督，同时避免整段回答的模仿；推理时不需要任何图形描述，在多个模型规模上达到或超过“推理时额外提供参考图形描述”的基座模型，并提升感知导向任务（尤其是低层几何感知任务）的表现，还能迁移到外部数学与感知基准；因为教师只评估纠正、不自行生成解答，同尺寸的冻结教师同样有效，只是在多数指标上增益小于更大的教师。
核心创新点
  • 最小编辑纠正式同策略蒸馏：教师借助参考图形描述与已验证参考解，只对学生的错误 rollout 按“最小编辑”评分，只让教师判为不可取的 token 进入纠正损失，正确的 rollout 则走任务奖励强化学习，从而在不做全响应模仿的前提下保留同策略监督。
  • 把感知信息前置到训练阶段：参考描述只作训练信号，测试时不需要额外标注，也不需要额外模型调用，却在多个模型规模上追平或超过推理时附带参考图形描述的基座模型。
