摘要总结
论文研究“计划声明—执行鸿沟”（Plan Declaration–Execution Gap），指出现有 planner–executor 系统无法仅凭最终任务成功率区分“选错计划”与“执行失真”两类失败。为此提出 Planning-as-Routing 框架：由 LLM 在 Predefined、Sequential、Hierarchical、Search 四种规划模式中声明其一，再由确定性路由器把任务分发给对应的模式专属执行器。在四个基准与三个 LLM 上的实验发现，通用 Plan+ReAct 在三个基准中仅 22%–45% 的轨迹能保持所声明的规划结构，而模式专属执行器能强制执行该结构，并将 ALFWorld 成功率从 0.48 提升到 0.92、SWE-bench Verified 从 0.36 提升到 0.44。
核心创新点
  • 提出 Planning-as-Routing 框架与“计划声明—执行鸿沟”这一新问题设定，用确定性路由器将 LLM 声明的四种规划模式（Predefined/Sequential/Hierarchical/Search）分发到模式专属执行器，从而把“模式选择”与“计划执行”解耦评估
  • 实证揭示通用 Plan+ReAct 难以保真执行所声明结构：在三个基准上仅 22%–45% 的轨迹保持声明结构，而模式专属执行器可强制执行预期结构
  • 发现规划模式有效性随环境与模型而变：ALFWorld 上 Search 最佳、SWE-bench 上 Hierarchical 最佳，且同一基准内不同模型的最优模式也会变化
  • 量化出收益主要来自执行环节（ALFWorld 0.48→0.92、SWE-bench Verified 0.36→0.44），并指出当前 LLM 仍不能可靠选取每个任务的最强模式，few-shot 示例仅在部分基准—模型组合上改善选择
解决的问题 / 适用场景
面向需要长程任务分解与可靠执行的 LLM Agent 系统（如网页/家居环境交互、代码修复与软件工程 Agent），用于诊断并修复“计划说得对但执行走样”的可靠性问题，指导 Agent 编排框架按任务类型选择并强制对应的规划执行模式。

突破 LLM 推理中同策略自蒸馏的规模限制
未明确披露
点击收起
摘要总结
本文用因子分析拆分了同策略自蒸馏（OPSD）中「教师上下文的正确性」与「学生轨迹（脚手架）的正确性」两个角色，发现脚手架正确性对下游准确率的影响强于上下文正确性：未经验证的脚手架会制造「模仿鸿沟」，因为教师使用了学生得不到的信息，而该鸿沟随模型规模增大而收缩，OPSD 却仍在监督大量未验证轨迹。基于此提出 OASIS，它保留 OPSD 目标但主要监督经最终答案标签验证的在策略轨迹，并用未经核验的模型自生成尝试替代书面参考解作为教师上下文，因此只需最终答案标签。在 Qwen3-1.7B、4B、8B 与 AIME 2024、AIME 2025、HMMT 2025 上，OASIS 平均比基座提升 3.2–3.8 分，而 OPSD 的增益从 1.7B 的 3.05 分跌至 8B 的 0.14 分；8B 上 OASIS 领先 OPSD 3.05 分。
核心创新点
  • 提出 OASIS：在标准 OPSD 目标下只监督「经标签验证」的在策略轨迹，并把教师上下文从书面参考解换成未经核验的模型自生成尝试，从而仅依赖最终答案标签、不需要参考解或过程标注
  • 用因子分析把教师上下文正确性与学生脚手架正确性分离为两个独立因素，实证得出脚手架正确性对下游准确率的作用大于上下文正确性，且未验证脚手架带来的「模仿鸿沟」随模型规模增大而缩小
  • 发现即使教师被条件化在学生自己失败的 rollout 上，经验证的脚手架仍能维持自蒸馏效果，说明「验证」比「优质教师上下文」更关键
  • 在 Qwen3-1.7B/4B/8B 与 AIME 2024、AIME 2025、HMMT 2025 上验证：OASIS 相对基座平均 +3.2~3.8 分，8B 时比 OPSD 高 3.05 分，修复了 OPSD 增益随规模衰减（3.05→0.14）的问题

摘要总结
论文指出流式视频理解需要增量维护对内容的记忆，而在线策略自蒸馏（On-Policy Self-Distillation, OPSD）虽能提供 token 级过程信号，直接套用却带来两个问题：(1) 学生模型无法端到端优化——记忆在问题到来之前就已写入，教师却用「问题+真值答案」特权打分，导致师生偏好错位；(2) 有效实体记忆崩塌——问题+真值特权使教师只偏好与问题相关的实体，且对记忆做 token 均值平均使信号与记忆覆盖的实体数无关，二者共同将记忆推向不利于流式多样性需求的方向。为此作者提出事件锚定自蒸馏（Event-Grounded Self-Distillation, EGSD），把流式记忆刻画为对可验证事件（关键视觉实体、动作与细节）的增量更新并在此之上针对性求解：对问题(1) 把 OPSD 信号改造成乘性权重并与结果奖励结合；对问题(2) 以事件作为特权信息对教师重新加权以抵消其问题相关性偏置，并加入实体覆盖奖励以补上 token 均值教师缺失的覆盖偏好。实验在主流在线与离线基准上取得强表现，StreamingBench 达 79.8%、OVO-Bench 实时赛道达 73.4%，记忆分析显示有效实体召回提升 17.4% 而记忆长度仅增加 6.8%。
核心创新点
  • 提出事件锚定的流式记忆表征，将记忆建模为对可验证事件（关键视觉实体、动作、细节）的增量更新，作为求解师生错位与记忆崩塌的统一基础。
  • 针对记忆早于问题写入导致的偏好错位，将 OPSD 的 token 级信号改造为乘性权重，并与结果奖励结合以实现学生的端到端优化。
  • 针对有效实体记忆崩塌，用事件作为特权信息对教师重新加权以抵消问题相关性偏置，并新增实体覆盖奖励以补足 token 均值教师所缺失的覆盖偏好。
  • 在 StreamingBench 取得 79.8%、OVO-Bench 实时赛道取得 73.4%，且记忆分析显示有效实体召回提升 17.4% 时记忆长度仅增加 6.8%，验证了精度与记忆开销的良好权衡。
解决的问题 / 适用场景
面向需要实时增量理解长视频流的在线系统，如视频问答、直播内容理解、可穿戴/机器人视觉助手等，在必须控制记忆长度开销的前提下，保持对多样关键实体与事件的长期覆盖和实时响应能力。
