摘要总结
论文聚焦软件工程智能体的上下文被工具观测主导、长交互历史维护代价高的问题，指出已有压缩方法会丢弃后续动作所需信息，而让智能体适配软 token 表征又会破坏其原有行为。为此作者提出 LOHA（Latent Observations, Hard Actions）上下文布局，把较早的工具观测压缩为软 token，同时保留智能体自身回合与最近 K 条观测的原始文本，并配合 Anchored Context Distillation (ACD) 训练法：把基座模型在全文本上的预测蒸馏到潜在视图，同时在纯文本输入上锚定同一基座模型的行为以抑制漂移。在 SWE-bench Verified 上，K=3 时每次调用上下文对 Qwen3-4B 减少 43%、对 SWE-Master-4B-RL 减少 57%，resolve rate 分别为 12.1% 与 21.8%（未压缩基线为 14.5% 与 27.5%）；K=8 时达到 14.4% 与 23.0%，且更大窗口通常更利于任务表现；在 32K token 限制下 Qwen3 K=3 在 199 实例子集上 resolve 21.1%，而同一适配智能体用全文本仅为 11.1%，单 GPU 并发服务吞吐达到全文本智能体的 1.9 倍。
核心创新点
  • LOHA 上下文布局：旧工具观测压成软 token，同时保留智能体自身回合和最近 K 条观测文本，兼顾历史压缩访问与近期内容精确引用
  • Anchored Context Distillation (ACD)：将基座模型全文本预测蒸馏进潜在视图，并以纯文本输入上的行为锚定约束行为漂移
  • 在 SWE-bench Verified 上给出压缩-性能定量权衡：K=3 分别降低 43%（Qwen3-4B）与 57%（SWE-Master-4B-RL）单次调用上下文，并发现更大观测窗口通常提升任务表现
  • 在 32K token 约束下，Qwen3 K=3 在 199 实例子集上 resolve 21.1%（同适配智能体全文本仅 11.1%），单 GPU 并发实例吞吐为全文本智能体的 1.9 倍

摘要总结
论文针对在线策略自蒸馏（OPSD）中“冻结教师”虽带来训练稳定、却使教师无法吸收学生在训练中获得的新改进这一矛盾，提出递归式自我改进框架。框架包含两个互补组件：动态协同演化（DCE）让携带真值上下文的特权教师副本与学生共同更新，使上一轮学到的修正指导下一轮；自精炼简洁学习（SRCL）则针对递归修正导致回复冗长、过度自我批判的问题，额外在模型自身在线响应的“更短且经验证的改写”上训练。在四种模型规模和四个竞赛级数学基准上，DCE+SRCL 一致优于 OPSD：Qwen3-8B 上取得 65.97% Average@12，比 OPSD 高 35.62 个百分点，且相比单用 DCE 平均输出长度下降 7.80%。
核心创新点
  • 提出动态协同演化（Dynamic Co-Evolution, DCE）：不再像 OPSD 那样冻结特权教师，而是让带真值的教师副本与学生协同更新，把每轮学到的修正递推到下一轮训练，从而移除冻结教师造成的性能上限。
  • 提出自精炼简洁学习（Self-Refined Concise Learning, SRCL）作为互补目标：在模型自身在线响应的更短、经过验证的改写上继续训练，抑制递归自我修正带来的冗长与过度自我批判倾向。
  • 在多种模型规模与四个竞赛级数学基准上验证 DCE+SRCL 稳定优于 OPSD，Qwen3-8B 上达到 65.97% Average@12，较 OPSD 提升 35.62 个百分点。
  • 实验发现简洁性目标可正交叠加：相对单用 DCE，加入 SRCL 后平均输出长度减少 7.80%，即在提升准确率的同时压缩推理链长度。
解决的问题 / 适用场景
解决的问题是在缺少外部强教师模型时，如何让模型用自己的带真值特权副本做可迭代的自我提升。适用于数学、竞赛题等答案可验证的推理任务，可用于提升 Qwen3 这类中小规模开源模型在推理与测试时扩展（test-time scaling）上的表现。

论文研究资源受限边缘节点上分布式模型推理中模型精度与通信开销的权衡问题，提出通过控制隐表示（latent representation）压缩程度来在满足严格QoS吞吐目标的前提下优化该权衡。在信道状态信息(CSI)已知时，作者对单任务导出闭式最优解，并将多任务问题归约为带逐链路注水（per-link water-filling）结构的凸优化程序；针对信道不可预测的动态环境，进一步提出仅依赖因果信道估计的随机对偶下降（stochastic dual descent）算法，并用Lyapunov分析证明其严格满足长期时延约束且最优性差距有界。论文通过仿真与真实边缘设备实验验证了该框架的有效性。
