摘要总结
论文指出 AI 虚拟细胞（AI virtual cell）即便在留出集上预测性能很好，也不能证明模型真的用到了输入的扰动信息，这一“预测—声明鸿沟”在 LLM 智能体依据打分反馈自行生成与修订预测器的 agentic model discovery 流程中尤其危险。为此作者提出 CELLAUDIT 审计框架，逐层追问：该输入能否进入被引用的计算路径、拟合后的预测是否依赖它、这种依赖是否真正改善了对观测响应的预测。在配对形态学—转录组扰动基准 BBBC047 上，智能体选出的预测器平均留出 Global PCC 达 0.3153，却对化合物替换完全不变（仅用对照谱的基线预测器为 0.3142）；源码检查定位到化合物查询通路被 singleton key-value attention 阻断，且换用不相交对照孔重拟合后该不变性依旧存在。对两个关联任务共 48 个候选的分层审计显示，47 个在化合物替换下两折预测都改变，但只有 20 个在两折上的目标损失增益置信区间均大于零；在 BBBC047 上，证伪引导的修订能恢复正的化合物平均贡献并保住相对对照谱基线的增益，在 sci-Plex 匹配搜索中审计增强的反馈也在五条轨迹上提升留出性能与化合物、剂量平均贡献（但配对区间跨零）。最后，在独立采集队列上重拟合固定设计表明：预测泛化并不意味着输入使用声明的泛化——剂量贡献仍成立，化合物身份的支持则消失。
核心创新点
  • 提出 CELLAUDIT 三层输入使用审计（可进入引用的计算路径 / 拟合预测是否依赖该输入 / 该依赖是否改善对观测响应的预测），把“是否用了输入”从留出集性能中解耦
  • 定位到具体失效机制：singleton key-value attention 阻断了化合物查询通路，使预测器在化合物替换下完全不变，且该不变性在不相交对照孔重拟合后仍复现
  • 量化预测性能与真实输入使用的背离：智能体预测器 Global PCC 0.3153 对比仅对照谱基线 0.3142，性能几无差异却对外宣称使用了扰动信息
  • 提出 falsification-guided revision，把 agentic 流程从 generate-score-revise 推进到 discover-falsify-revise；在 BBBC047 恢复正化合物贡献、在 sci-Plex 五条轨迹上以 audit-enriched 反馈提升留出性能与化合物/剂量贡献
  • 在独立采集队列上验证预测泛化不等于输入使用声明的泛化：剂量贡献保持而化合物身份的支持消失
解决的问题 / 适用场景
面向自动科研（LLM 智能体驱动模型发现）与生物医学建模场景，用于在药物扰动响应预测、靶点/化合物效应筛选等任务中甄别模型究竟是学到达了扰动机制还是仅仅拟合了对照基线，避免把“假相关”当成可交付的机制结论。

LabourCrew：面向可信对抗式审议与劳动法成文法推理的多智能体 RAG 框架

点击收起
摘要总结
针对成文法问答中“每个论断都必须可溯源到证据、而不只是相关”的硬性要求，本文提出多智能体 RAG 框架 LabourCrew，指出单轮 RAG 无法识别证据不足、而现有多智能体法律辩论系统把 grounding 当作提示约定、允许 agent 引用未检索到的证据。其三个 grounding 机制是：StatuteGraph 图索引显式链接章、节、但书（proviso）与交叉引用结构而非固定长度文本块；Evidence Exchange Protocol 将辩护方与解释者限制在 evidence ledger 内，使引用未检索文本在机制上不可能，并用容错 supervisor board 并行运行辩护 agent 使个别失败只降级不崩溃；Calibrated Trust Gate 用信任分数替代分类式接受/拒绝，借助 conformal risk control 阈值化给出假接受率的无分布上界。在 LabourActQA（源自《孟加拉国劳动法 2006》的 500 题孟加拉语问答集，覆盖 7 类推理、3 个难度层级）上把经验假接受率压到 0.081（目标 α=0.10），Answer Relevancy 达 0.862，高于 HyDE RAG（0.839）、Graph-RAG（0.815）、Hierarchical RAG（0.828），且随题目难度上升性能渐变退化而非崩塌。
核心创新点
  • StatuteGraph：按章、节、但书与交叉引用结构显式建链的图索引，用结构化法条依赖替代固定长度切片作为检索与 grounding 单元。
  • Evidence Exchange Protocol：把辩护 agent 与解释者约束在证据账本内，使“引用未检索文本”在流程上不可发生；并以容错 supervisor board 并行运行辩护方，实现单点失败只降级不崩系统。
  • Calibrated Trust Gate：用连续信任分数加 conformal risk control 阈值取代二元 accept/reject，给出假接受率的无分布（distribution-free）风险界，实测假接受率 0.081 ≤ α=0.10。
  • 构建 LabourActQA 评测集（《孟加拉国劳动法 2006》500 题孟加拉语问答，7 类推理 × 3 档难度），并实证得出低资源成文法域中 Answer Relevancy 0.862 领先 HyDE RAG/Graph-RAG/Hierarchical RAG，且难度升高时性能平缓退化。
解决的问题 / 适用场景
解决低资源法域中劳动法问答答案不可审计、证据不足时系统仍强行作答并可能给出错误劳动权益结论的问题。适用于要求可溯源引用与“证据不足即弃答”的法律咨询、合规审查类问答系统，尤其是孟加拉语等低资源语言的法条检索与权益解读场景。

控制令牌注入抑制思维链：击穿工具调用智能体的推理式监督
未明确披露
点击收起
摘要总结
本文论证工具调用型语言模型智能体的安全性并非模型单方面的属性，而是模型与解码框架（聊天模板渲染、工具调用解析器、解码 harness）的联合属性，且两侧都能被不可信输入攻击。作者在公开的 gpt-oss-20b 推理模型及其官方工具沙箱上，通过在用户消息末尾追加一段模型自身的通道控制令牌，使分词器把推理轮渲染为「已经结束」，模型于是不输出任何思维链、直接发起工具调用：在模型本就能完成的 40 个任务上，推理通道从平均 52.5 个 token 降到 0，而工具调用在每次试验中照常触发。这种「无推理轨迹」状态同时击穿了规则监控与跨家族 LLM 监控（两类监控在普通试验上全检出、在伪造试验上零检出），对明显恶意请求还能把 39.6% 的模型拒绝转化成已完成的数据外泄。代码与逐次试验日志已开源（github.com/Usama1002/deleting-the-trace）。
核心创新点
  • 把 Agent 安全从「模型属性」重新定义为「模型 + 解码 harness 联合属性」：明确拆出聊天模板渲染、工具调用解析器、解码框架三个非模型环节，并用全精度受控实验证明二者都可被不可信输入攻击
  • 提出控制令牌注入（control-token injection）攻击：在用户消息尾部拼入模型自身的 channel-control 令牌，让分词器把推理轮渲染成「已完成」，从而在不触碰模型权重的前提下从源头消除思维链，40 个任务上推理 token 由均值 52.5 降至 0，而危险工具调用仍每次触发
  • 揭示解析器决定论：完全相同的贪婪解码输出是否「触发工具调用」由 harness 解析器而非模型决定——容错的截断正则会触发缺少结束令牌的调用，严格正则则丢弃；Gemma agent 官方发布的两个解析器在同一批生成上给出 24/24 触发与 0/24 触发两个相反结果
  • 实证现有推理式监督的失效边界：规则监控器与跨家族 LLM 监控器对所有普通试验检出、对所有伪造试验零检出，对公开恶意请求把 39.6% 的拒绝改写为完成的外泄；并证明该抑制可间接投递、跨聊天模板依赖，另在两种以上推理模型上复现
  • 系统评估防御并给出其局限：输入净化、解析器加固、空推理检测三类防御中，「标记缺失推理轨迹」能抓住基础攻击，但会被自适应的良性诱饵绕过
解决的问题 / 适用场景
面向部署工具调用型 Agent（带 shell、文件、网络等工具）的平台方与 Agent 安全评测方向：说明只做模型侧对齐不足以保证安全，必须把聊天模板渲染、工具调用解析器和推理轨迹缺失检测一并纳入加固与审计范围，并将「不受信任输入直达解码链路」视为核心攻击面，尤其适用于存在数据外泄风险的企业级 Agent 与推理式监督（monitor）系统。

摘要总结
论文针对多约束指令遵循中模型难以同时满足多条激活约束的问题，指出既有方案（外部验证器/评分器的序列级与词元级 RL 奖励，或对单一全上下文教师的在线策略蒸馏 OPD）会随约束数量增加而被稀释。作者提出 CC-OPD，反转蒸馏中监督信号的构造方向：不从学生可见信息之外去增强教师，而是轮流将每一条约束从教师的条件中消融，用由此产生的逐词元概率差构造单约束信号，并将留一法对数似然偏移求和、裁剪后作为词元级塑形项叠加到原始 OPD 奖励上。全部塑形项来自冻结教师，蒸馏过程无需外部验证器，且当聚合偏移为零时奖励退化为原始 OPD。在两个 Qwen 模型对与七个基准上，CC-OPD 在学生训练方法中取得最高平均成绩，且用 CC-OPD 训练的 1.5B 学生模型在 MulDimIF 基准上超过了其自身的 7B RL 教师。

  • 提出 CC-OPD（反事实约束条件化在线策略蒸馏），通过逐条消融教师条件中的约束，从逐词元概率差分中构造每条约束的专属监督信号，扭转了传统蒸馏“向教师注入学生看不到的信息”的方向
  • 将留一法的逐词元对数似然偏移聚合并裁剪，作为词元级塑形项加在原始 OPD 奖励之上，聚合偏移为零时精确退化为原始 OPD，保证方法不损害基础蒸馏信号
