超越置信度：通过检索支撑实现多轮搜索智能体的测试时扩展
未明确披露
点击收起
摘要总结
本文研究面向多轮搜索智能体的测试时扩展，发现为单轮推理设计的基于置信度投票方法难以迁移到会检索外部文档的 Agent 场景。其根因是 copy inflation：检索文档被拼接进上下文后，智能体从文档复制的 token 会获得系统性偏高的 log probability，导致同一问题的多个 rollout 置信度差异被压平。作者提出 Retrieval-Grounded Voting（RGV），通过最终答案与各 rollout 检索文档之间的词汇重叠度进行外部评分，避免使用受污染的 log probability，也不需要额外调用 LLM；在四个搜索智能体基准和五个 LLM 上，RGV 相比置信度投票最高提升 5.4% 准确率，在正确答案仅出现在 8 个 rollout 中 1 至 2 个的 minority-correct 问题上最高提升 35%。
核心创新点
  • 识别并命名多轮检索 Agent 中的 copy inflation 现象：检索文档进入上下文后，被复制的 token 具有异常偏高的 log probability，从而破坏置信度加权投票。
  • 提出 Retrieval-Grounded Voting（RGV），使用最终答案与该 rollout 检索文档的 lexical overlap 作为投票信号，将评估依据移出受检索内容污染的生成上下文。
  • RGV 不依赖 token log probability，也不需要额外的 LLM 调用，因此能够以较低额外成本对并行搜索轨迹进行测试时聚合。
  • 在四个搜索 Agent benchmark 和五个 LLM 上验证了稳定收益：相较 confidence-based voting，准确率最高提高 5.4%，在 minority-correct 问题上最高提高 35%。
解决的问题 / 适用场景
适用于需要让多个搜索智能体并行检索、再从候选答案中选择最终结果的问答、知识检索和研究助理系统。它尤其适合正确证据只被少数轨迹检索到的任务，可提升稀有正确答案在聚合阶段被保留的概率。

核心创新点
