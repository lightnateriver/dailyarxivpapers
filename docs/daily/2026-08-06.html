Agentic Reinforcement Learning with Observation-Calibrated Self-Distillation
未明确披露
点击收起
摘要总结
大语言模型智能体通常通过稀疏的轨迹级奖励进行强化学习训练，但这类奖励难以指导单个 token 的更新强度。已有的 On-Policy Self-Distillation (OPSD) 方法通过特权回放视角对生成 token 重新打分以获得密集的 token 级监督，但本文指出其中存在混淆问题：所得信号既包含回放视图中的特权信息，也包含回放脚手架本身引起的分数偏移，难以归因。本文提出 Observation-Calibrated Self-Distillation (OCSD)，对比结构匹配的完整与观测消融两个回放视图，提取仅由真实未来观测带来的残差，消除回放脚手架带来的共享分数变化，并以此残差在高不确定步骤调节 token 级 GRPO 更新、同时保留轨迹级更新方向。在 ALFWorld、WebShop 和 Search-QA 三个基准及三种 Qwen3 模型规模上，OCSD 一致优于强基线，诊断分析也证实校准残差与局部环境反馈更对齐。
核心创新点
  • 识别出 OPSD 的混淆问题：特权信息与回放脚手架引起的分数偏移交织，导致 token 级监督难以归因到具体信息
  • 提出观测校准自蒸馏 (OCSD)：构造仅差在是否包含真实未来观测的两个结构匹配回放视图，通过对比求观测残差，剔除回放脚手架的共享分数变化
  • 残差驱动的训练机制：在模型高不确定的步骤用观测残差调制 token 级 GRPO 更新，同时保持轨迹级更新方向不变
解决的问题 / 适用场景
解决 LLM 智能体强化学习中稀疏轨迹奖励缺乏 token 级学习信号、且自蒸馏监督易被回放机制污染的问题，适用于 ALFWorld（具身操作）、WebShop（网络购物）、Search-QA（搜索问答）等需要环境观测反馈的智能体任务。

  • 四角色分工与门控采纳机制：Manager/Planner/Engineer/Reviewer 分工协作，所有新知识（记忆、技能、流程、路由决策）必须经过角色审查和任务原生验证才能进入系统
  • 验证驱动的容错与恢复：通过验证器恢复（34 次）和严格评审回路救援（22 次）机制，能在失败、隐藏约束或目标失配时自动回滚并转向

摘要总结

  • 设计金丝雀探针工具机制，可植入任意 MCP 工具集，通过降低诱饵短语的提示性验证模型靠的是真实推理而非关键词匹配
  • 揭示分类法具备能力分层特性：能力幻象最易困住前沿模型，其余类型对强模型几乎无效、只在小模型上触发，可凭能力而非强度区分模型

摘要总结
长上下文推理中，单次推理轨迹必须同时完成上下文探索、中间状态存储、证据验证与最终答案生成，一旦早期出错就会沿轨迹传播至最终结果。本文提出 Chained Recursive Language Models（Chained RLM），一种推理时架构：同一模型被反复调用为一系列全新的推理根（fresh reasoning roots），每个根只接收原始问题、上下文，以及前序根写入的紧凑纯文本摘要、文本黑板和持久任务工件，而非继承完整对话历史。其动机是把大问题切分为部分任务（partial tasks）分阶段计算，使中间工件可被后续新鲜推理检查、修正和扩展。论文描述了系统模型、交接机制、工件工作区与评估协议，并研究了在何种条件下新鲜上下文的工件延续相比直接回答甚至递归工具调用能带来可测量的准确率提升。
核心创新点
  • 全新推理根机制：重复调用同一底层模型作为一系列无历史继承的独立推理入口，避免早期错误沿单一轨迹传播累积
  • 轻量交接协议：以紧凑纯文本摘要 + 文本黑板 + 持久任务工件在前后推理根之间传递状态，而非维护完整对话上下文
  • 分阶段计算范式：将一次大型推理响应切分为可独立检查、修正、扩展的部分任务，中间产物可被后续推理根复查与改写
  • 工件工作区与系统化评估协议：建立交接机制和评估流程，量化新鲜上下文工件延续相比直接回答和递归工具调用的增益边界

解决长上下文推理中单次推理轨迹负担过重、早期错误持续传播的问题，适用于需要抽取、计数、排序或多跳推理等长程推理任务。

社交媒体上大量随手拍摄的单目视频与图像为沉浸式内容创作提供了丰富素材，但如何在输入覆盖极度有限的情况下生成具备精确相机控制与几何一致性的新视角仍是难题。基于重建的方法（NeRF、3DGS）在稀疏输入下性能严重退化，且难以显式处理遮挡；生成式方法虽降低数据依赖，却常因几何引导不准确或隐式而在大基线视角合成上表现不佳。为此作者提出 UniWorld-View，一个从单目输入实现可控大基线新视角合成的统一框架，将显式 3D 引导与生成式扩散建模相结合。配合视频扩散主干，即使在大幅相机运动与宽基线变化下也能生成高保真新视角，并可输出多视角视频供下游动态 3DGS 重建使用。
核心创新点
  • 统一框架：将显式 3D 几何引导与生成式扩散建模融合，实现精确相机控制与几何一致的新视角生成
  • 遮挡感知点云渲染策略：显式解决可见性歧义，为扩散合成提供准确可靠的几何先验
  • 依托视频扩散主干，支持极端相机运动与宽基线变化下的高保真新视角及多视角视频生成，可直接服务下游动态 3DGS 重建
  • 在 WorldScore 基准与零样本 NVS 基准上验证了框架在可控性、几何一致性与视觉保真度上的优势
解决的问题 / 适用场景
解决稀疏单目输入下大基线新视角合成难题——在输入覆盖极少且存在遮挡的情况下，生成照片级真实、几何一致、相机可控的新视角。适用于基于社交平台随手拍摄的单目视频/图像驱动的沉浸式内容创作，以及动态 3DGS 重建等下游应用。
