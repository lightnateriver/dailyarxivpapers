ANTE: Anticipate, Then Execute -- Learning Internal World Models for Coding Agents from Verified Beliefs
ANTE：先预判，再执行——从可验证信念中为编码智能体学习内部世界模型
未明确披露
点击收起
摘要总结
在容器化环境中的代码智能体只依据历史工具响应决定后续动作，普遍不做前瞻：策略不预判动作后果，且终端奖励难以把失败归因到具体早期步骤，一次误判编辑可能在信号到达前就已不可逆地破坏仓库状态。现有代码世界模型要么在强化学习前被冻结，要么只退化为对环境下输出的辅助下一 token 损失。作者提出 ANTE（Anticipate, Then Execute），用真实执行校验策略的动作前预测，并将其转化为动作与“信任/弃权”决策的逐步信用；其中 Belief-Anchored Policy Optimization（BAPO）以策略自身预测为锚计算逐步优势，ANTE-TTO 测试时优化则无需外部打分器即可在候选动作中择优。在 SWE-bench Verified 上把 Qwen3-32B 的 pass@1 从 25.0% 提升到 57.2%，比无信念状态的匹配 GRPO 基线高 6.2 个百分点，世界模型准确率在 RL 过程中从 44% 升至 69%。
核心创新点
  • ANTE 智能体式 RL 框架：用真实执行结果验证策略的动作前预测，把预测结算为动作及 trust-or-abstain 决策的逐步信用（per-step credit），解决终端奖励难以归因早期失败步骤的问题。
  • 提出 Belief-Anchored Policy Optimization（BAPO）：在每个动作前显式陈述内部信念，并将信用锚定在策略自身预测上以生成逐步优势。
  • 提出 ANTE-TTO 测试时优化，利用已训练的前瞻预测在候选动作间选择，无需任何外部打分器即可实现 test-time scaling。
  • 实验发现：Qwen3-32B 在 SWE-bench Verified 上 pass@1 由 25.0% 升至 57.2%（高于匹配 GRPO 基线 6.2 个百分点），世界模型预测准确率在 RL 中由 44% 提升到 69%，且前瞻能力可跨 harness 与分布外域迁移。
解决的问题 / 适用场景
面向容器化仓库中执行长程任务的编码/软件工程智能体，用于在编辑前预判其后果并及时弃权，避免错误改动不可逆地污染仓库状态，同时无需外部打分器即可在推理时扩展候选动作搜索。

ECMR: Evidence-Aware Deliberation Control for Multi-Agent LLM Reasoning
ECMR：面向多智能体 LLM 推理的证据感知审议控制
未明确披露
点击收起
摘要总结
论文把多智能体 LLM 系统在推理前就锁定固定审议协议所带来的失败，定义为“语义假共识”（semantic false consensus）：一个高置信度的群体答案实际上由狭窄、重复或彼此相关的理由支撑，而固定协议既无法对已解决与未解决样本区别分配算力，也会把重复支持误当成独立确认。为此作者提出 ECMR——运行在冻结的角色条件化 LLM 之上的证据感知控制器，它在每一步汇总答案集中度、支撑理由的多样性与独立性、矛盾情况、角色行为、验证历史与剩余预算，再决定下一步执行提议、质疑、验证、仲裁、多元化、角色纠正还是停止，并把该决策形式化为有限时域预算控制问题，推导出状态条件化、风险触发验证与角色纠正能提升成本调整效用的充分条件。在 MedQA、CaseHOLD、FinQA 共 9,000 条声明留出记录的评测中，ECMR-Full 将汇总准确率从 62.1% 提升到 84.9%，将假共识率从 40.7% 降到 17.0%，并将证据支撑率从 58.0% 提升到 88.7%；状态打乱（state shuffling）消融损失 11.7 个准确率点却只减少 0.7 轮，更难的轨迹会从提前停止转向仲裁。作者也指出 ECMR-Full 消耗最大 token 预算，因此它带来的是绝对可靠性最强，而并非在 token 效率上一致占优。
核心创新点
  • 提出并刻画“语义假共识”这一新失败模式：高置信度群体答案由狭窄、重复或相关的理由支撑，指出仅凭重复支持推断独立确认的不可靠性。
  • 设计 ECMR 证据感知控制器，直接以状态特征（答案集中度、支撑多样性与独立性、矛盾、角色行为、验证历史、剩余预算）驱动动作选择，涵盖提议、质疑、验证、仲裁、多元化、角色纠正与停止。
  • 将多智能体审议控制形式化为有限时域预算控制问题，并给出状态条件化、风险触发验证与角色纠正可提升成本调整效用的充分条件。
  • 在 MedQA、CaseHOLD、FinQA 的 9,000 条记录上实证：准确率 62.1%→84.9%、假共识率 40.7%→17.0%、证据支撑率 58.0%→88.7%；状态打乱消融掉 11.7 个准确率点而仅省 0.7 轮，证明状态条件化不可替代。
解决的问题 / 适用场景
适用于在医疗问答、法律案例判断、金融数值推理等高风险领域部署多智能体 LLM 的场景，用于防止群体答案因理由同源而虚假达成一致，并让推理预算按题目难度动态分配。尤其适合需要对审议过程与证据链做审计、且算力成本受限的线上推理服务。

  • 在多种推理基准上以接近单智能体级别的 token 成本达到多智能体级别性能，在成本—效果折中上明显优于静态辩论与投票基线。

摘要总结
论文指出递归推理器（对隐状态反复施加同一学习到的更新规则）的两种测试时扩展方式——增加更新步数的深度扩展与扰动隐状态生成多轨迹的宽度扩展——都会收敛到错误的吸引子，无法像人一样“换角度重想”。为此作者提出 Input-Conditioned Search (ICS)，不增加任何训练，而是搜索输入条件以诱导预训练递归推理器产生不同的 update map，从而在同一个隐状态上探索多样的推理轨迹。在六个推理任务上 ICS 取得最高平均准确率，且所需模型 FLOPs 比所对比的扩展基线最多少两个数量级；控制实验证实 ICS 能把轨迹从同一状态重定向，理论分析与严格数值验证进一步表明 ICS 可局部消除错误的吸引不动点。

解决的问题 / 适用场景
适用于以隐状态迭代递归推理的模型（循环深度推理器）在部署阶段的推理效率与正确率权衡，面向数学、逻辑等需要反复迭代思考的测试时推理服务与算力受限的推理加速场景。

摘要总结
本文系统检验了自蒸馏是否真能提升大模型推理能力，重新评估了两种代表性方法 Self-Distillation Policy Optimization (SDPO) 与 On-Policy Self-Distillation (OPSD)。作者在代码、科学、工具调用与数学推理四类任务上复现实验，覆盖 Qwen3（1.7B–14B）与 OLMo-3-7B 多规模模型，发现这些方法报告的性能增益并不能稳定泛化到未见问题上，其提升主要来自过拟合或对已有推理行为的迁移，而非有效利用正确答案、环境反馈等特权信息（privileged information）。进一步的梯度分析显示，自蒸馏梯度与直接优化期望奖励的策略梯度对齐度较弱，因此作者认为如何真正利用特权信息提升推理仍是待解决的开放问题。
核心创新点
  • 对 SDPO 与 OPSD 两类代表性特权信息自蒸馏方法进行统一复现与跨任务检验，覆盖代码、科学、工具调用、数学四类推理任务。
  • 发现自蒸馏的收益不能稳定迁移到未见问题，增益主要由过拟合训练分布或迁移已有推理行为解释，而非真正使用特权信息。
  • 通过梯度对齐分析指出自蒸馏梯度与直接优化期望奖励的策略梯度弱对齐，质疑其作为策略改进方向的有效性。
  • 在 Qwen3（1.7B–14B）与 OLMo-3-7B 多规模模型上给出实证结论，并把“有效利用特权信息改善推理”定位为开放挑战。
解决的问题 / 适用场景
适用于评估与选型 LLM 后训练方案（自蒸馏 vs 强化学习）的研发团队：当考虑用正确答案或环境反馈做特权信息蒸馏来提升代码、数学、工具调用等推理能力时，本文提示这类增益可能不可泛化，需以域外测试集和梯度对齐诊断来验证，避免被分布内指标误导。

摘要总结

摘要总结
针对联合嵌入预测架构（JEPA）在潜在空间中学习世界模型时，无约束自回归预测器会在长时程 rollout 中收缩潜在分布的问题，论文提出辛哈密顿 JEPA（Symplectic Hamiltonian JEPA，LeHami）。该方法把标准预测器换成动作条件化的哈密顿流（action-conditioned Hamiltonian flow），在结构化的 (q, p) 潜在状态上用严格辛（exactly symplectic）的 leapfrog 步进积分，使每一步 rollout 都保持相空间体积，并在数学上排除均匀收缩、渐近稳定不动点以及不同潜在状态合并，且该性质不依赖于学到的参数或动作序列。动量类分量由所学位置类表示的时间导数得到，为预测与控制提供显式二阶状态。在保守与受驱动的视觉摆（visual pendulum）环境中，LeHami 相对无约束 JEPA 世界模型显著改善长时程速度预测，经验上保持恒定潜在体积而基线出现收缩，并支持在未见过的亚帧步长下精确积分与数值时间反演。
核心创新点
  • 提出 Symplectic Hamiltonian JEPA（LeHami），用动作条件化的哈密顿流替换 JEPA 的标准自回归预测器，在 (q, p) 结构化潜在状态上以 exact symplectic 的 leapfrog 步进积分
  • 给出与参数无关的推理时保证：每一步 rollout 保持相空间体积，排除均匀收缩、渐近稳定不动点与不同潜在状态合并，且结论独立于学习到的参数和动作序列
  • 由学习到的位置类表示的时间导数构造动量类分量，得到显式二阶潜在状态，使同一动力学可直接用于预测与控制
  • 在保守与受驱动的视觉摆环境中，长时程速度预测显著优于无约束 JEPA 基线，经验上维持恒定潜在体积，并支持未见亚帧步长的精确积分与数值时间反演
解决的问题 / 适用场景
解决潜在世界模型长时程 rollout 时潜在状态坍缩、信息丢失、预测随步数退化的问题。适用于基于视觉的机器人控制、模型预测控制（MPC）以及需要多步前瞻的世界模型训练，也适合要求积分精度对步长鲁棒或需时间反演对称的物理仿真与控制任务。
