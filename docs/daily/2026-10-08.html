GraphOPD: Graph-Augmented On-Policy Distillation for LLM Agents
GraphOPD：面向 LLM Agent 的图增强在策略蒸馏
未明确披露
点击收起
摘要总结
论文指出，在策略蒸馏（on-policy distillation）用教师策略为学生 Agent 提供步级密集监督时，现有做法按每步教师-学生散度大小分配监督，这一单轮直觉在多轮决策链中会失效：早期漂移会进入后续每一步的上下文，使教师与已漂移的轨迹保持一致而非标记其起因，同时可互换步骤会产生大但与结果无关的散度，作者在 agentic 基准上验证按最高散度蒸馏相对随机选择的收益并不一致。为此提出 GraphOPD，首个把基于图的结构增强引入 Agent 能力在策略蒸馏的方法：它从环境自身的状态变更记录中读取哪些步骤使能了哪些后续步骤，构建依赖图，用图上的随机游走平稳分布为每步打分，并把该结构信用与散度信号融合为轨迹相对掩码，把监督集中到每次 rollout 中最高适配度的步骤。在 ALFWorld、WebShop、SearchQA 上覆盖三种模型规模与 11 个基线，GraphOPD 全程表现有竞争力，最高比最强基线提升 +5.8 pp。
核心创新点
  • 提出 GraphOPD，首个将基于图的结构增强（graph-based structural augmentation）引入 Agent 能力在策略蒸馏的方法。
  • 从环境自身状态变更记录中推断步骤间的使能/依赖关系并组织为依赖图，规避了会被漂移污染的教师-学生散度信号，再用依赖图上的随机游走平稳分布为每个步骤计算结构信用分。
  • 把结构信用与散度信号融合为轨迹相对掩码（trajectory-relative mask），将监督集中到每个 rollout 中最高适配度的步骤；执行回放审计证明两种融合信号各自独立必要。
  • 在 ALFWorld、WebShop、SearchQA 三种模型规模、11 个基线上验证，较最强基线最高提升 +5.8 pp；审计还显示该结构信用分以远高于随机的水平追踪真实因果影响，并可迁移到域外工具集成推理。
解决的问题 / 适用场景
用于在仅有稀疏的轨迹级奖励时，为多轮 LLM Agent 的在策略蒸馏提供更可靠的步级信用分配，适用于网页/环境导航、搜索问答、工具调用等需要连续多轮交互决策的 Agent 训练系统。

摘要总结

核心创新点

  • 提出 MoSDOT（Mode-Support Semi-Discrete Optimal Transport），将多模态回放聚合成具有规定容量的有限模态支撑集，用条件半离散最优传输在教师训练前为每个噪声样本分配单一模态
  • 设计共享随机性的执行变体，在推理时引入共享噪声分量，用于量化严格乘积式去中心化执行所固有的残差差距
  • 在受控诊断与离线MARL基准上验证 MoSDOT 提升端点质量与路由一致性，且在多模态联合行为数据集上增益最大

摘要总结
论文针对循环Transformer（Looped Transformer）——通过多次循环复用共享Transformer块来在不增加参数量的前提下提升计算深度——指出其KV缓存显存仍随循环次数增长，成为限制批大小与推理吞吐的关键瓶颈，而现有KV量化在激进低精度下精度损失严重。作者观察到循环之间KV状态高度相似，据此提出 ResidualQuant：以最后一轮的KV状态为参考，用低精度残差表示其余各轮循环，并进一步结合最小二乘缩放与作用于残差的旋转，以及逐循环混合精度，实现低至INT2的精确量化并保持高效重建。在多个循环Transformer模型及数学推理与代码生成基准上，ResidualQuant 一致优于基于旋转的最先进KV量化方法：混合精度下精度接近BF16，理论KV存储减少80.7%，相同显存预算下精度比旋转类基线最高高13.0%；在 RTX 5090 上固定批解码吞吐最高提升2.73倍，更小的显存占用支持最高2倍批大小，峰值吞吐最高提升4.15倍。
核心创新点
  • 发现循环Transformer各轮KV状态高度相似这一特性，提出 ResidualQuant：以最终轮KV状态为参考、用低精度残差编码其余轮次，而非对每轮独立量化
  • 组合最小二乘缩放（least-square scaling）与施加于残差的旋转（rotations），并采用逐循环混合精度（loop-wise mixed precision），将KV缓存量化推进到INT2仍可高效重建
  • 混合精度设置下精度接近BF16，理论KV存储减少80.7%，相同显存预算下比旋转类KV量化基线精度最高高13.0%
  • 在 RTX 5090 上实测固定批解码吞吐最高2.73倍、峰值吞吐最高4.15倍（批大小最高2倍）的提升
解决的问题 / 适用场景
面向采用循环/递归共享权重架构的大模型推理服务，在显存受限的GPU上部署长上下文数学推理与代码生成任务时，通过大幅压缩KV缓存显存来放大批大小、提升解码与峰值吞吐。

  • 提出协作推理蒸馏（CRD）框架，采用交互式交叉反馈让多个教师在推理过程中迭代相互批判、改进彼此的推理。
  • 引入细粒度分步质量评估，在不依赖最终答案的情况下判断每一步推理的逻辑有效性，从而把可靠推理与侥幸猜对区分开。
  • 设计连贯性感知步骤拼接（coherence-aware step stitching），将各教师推理中的互补优势合成为连贯的学生训练数据。
  • 用带预算约束的推理质量优化（RQO）训练学生模型；CRD-4B 以 5 万样本在 MATH-500 取得 97.3%、AIME'25 取得 70.3%，训练数据量比同类模型小至多 12 倍。
解决的问题 / 适用场景
用于把强模型的数学与逻辑推理能力以低算力和小数据量蒸馏到 4B 级紧凑模型，适用于部署预算受限但仍需可靠推理能力的下游推理服务场景。
