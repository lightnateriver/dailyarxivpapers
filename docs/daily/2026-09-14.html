GTA：面向 LLM 图算法推理的图论智能体与基准
未明确披露
点击收起
摘要总结
本文追问 LLM 能否可靠地用自然语言完成多步图算法推理，指出现有评测存在三类缺陷：只在小图上做简单任务、只给代码生成打分而不考察对图本身的推理、或把输入格式固定为单一表示，因此无法反映真实能力。作者构建了 Graph Theory Bench（GT Bench）：覆盖 24 个经典图问题、44 种任务—结构设定、超过 10 万条样例，并提供自然语言、结构化语言、邻接表、邻接矩阵四种图表示；对八个 LLM 的评测表明准确率强烈依赖输入表示，最优表示会随图密度、规模、拓扑以及模型本身而变化，且这种敏感性在最强调理模型上只是减弱并未消失。基于该发现作者提出 Graph Theory Agent（GTA），把一个经偏好训练得到的表示选择器与 plan-and-decompose 规划分解脚手架组合在一个冻结的执行 LLM 之外，使 Phi-4 在 easy split 上从 53.5% 提升到 69.1%、hard split 上从 33.0% 提升到 41.5%，优于八种 prompting 与 agent 基线，并可无重训迁移到 GraCoRe 与 NLGraph。
核心创新点
  • 构建 GT Bench 基准：24 个经典图问题 × 44 种任务—结构设定、10 万+ 样例，且同时提供自然语言、结构化语言、邻接表、邻接矩阵四种表示，评测对象是图上的推理过程而非代码生成。
  • 给出关于输入表示敏感性的实证结论：LLM 图推理准确率强依赖表示格式，最优表示随图密度、规模、拓扑和模型迁移，且在最强推理模型上依然存在（仅被削弱）。
  • 提出 GTA 智能体架构：偏好训练（preference-trained）的表示选择器负责为每道题选输入格式，plan-and-decompose 脚手架负责多步拆解，二者围绕一个冻结的 executor LLM 工作，无需微调执行模型。
  • 在 GT Bench easy/hard split 上把 Phi-4 从 53.5%/33.0% 提升至 69.1%/41.5%，超过八种 prompting 与 agent 基线，并零重训迁移到 GraCoRe 和 NLGraph，同时开源基准生成与评测代码并提供项目主页。
解决的问题 / 适用场景
面向所有需要让 LLM 处理图结构数据的落地系统，例如知识图谱问答、依赖/调用关系与网络拓扑分析、流程图与图算法求解类助手：让系统在部署时自动挑选最合适的图输入表示并配合智能体式任务分解，在不重训模型的情况下提升多步图算法求解的正确率。

  • 提出 two-gap framework，用需求鸿沟与模型鸿沟统一解释智能体软件工程的主要失效模式，说明 reward hacking 利用需求或模型的遗漏、hallucination 则通过编造需求与环境假设放大鸿沟。

  • 提出 assurance-revision loop（保障-修订循环），以部署证据为触发信号，在输出被拒收时修订需求、环境模型或评估器，使验证从部署前代理指标延伸到部署后现实反馈。

  • 以“现实是最终验证者”收束：实际部署条件下可接受的行为才是最终测试，部署前评估只是其代理指标。
解决的问题 / 适用场景
