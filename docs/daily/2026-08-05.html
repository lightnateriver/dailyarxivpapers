Should We Type or Talk to LLM Agents? A Comprehensive Study of Voice and Keyboard Input Perturbations
未明确披露

摘要总结
本文系统性研究了语音与键盘两种人类输入通道的扰动对 LLM Agent 性能的影响，提出了 HIVE（Human Input-Variation Engine）评测套件，涵盖语音转写扰动（口语非流利、AI 转写重构）与 QWERTY 键盘扰动。实验发现：语音转写扰动会显著降低所有指令微调模型的准确率，且代价来自转写结构而非填充词；键盘扰动代价较小，模型能吸收大量扰动。两类扰动的伤害都归结于同一个根因——问题中被破坏的 token 数量：摧毁 token 才会造成损失，而新增 token 代价很小。此外，增加思考预算（thinking budget）几乎能完全恢复键盘通道的性能，但对语音通道无效，压缩语音配合思考预算反而更差。
核心创新点
  • 提出 HIVE，一套同时覆盖语音转写扰动与 QWERTY 键盘扰动的统一评测套件，首次系统对比两种输入通道对 LLM 的影响
  • 通过扰动归因实验发现伤害的统一根因是问题 token 的存活数量，而非扰动类型本身，解释了两种通道差异的机制
  • 揭示思考预算对两类扰动的差异化缓解效果：可几乎完全恢复键盘扰动，却对语音扰动无效甚至加剧压缩语音问题
  • 严格排除了测试集污染与轻量适配（轻量训练无法消除）等替代解释，并发现两通道差距仅出现在需构造/推导答案的任务上，多选题上无差异
解决的问题 / 适用场景
面向语音助手与 Agent 交互场景：当用户通过语音或键盘与 LLM 交互时，评估模型对真实输入噪声（转写错误、口语句式、误打）的鲁棒性，为语音交互系统设计、输入纠错与推理时缓解策略提供依据。

摘要总结
VerMem（Verifiable Memory）提出统一记忆管理框架：将长期记忆（LTM）、活动上下文和情景历史表示为不同状态，用一个记忆操作策略控制七种原子操作（增/改/软删 LTM、检索入上下文、过滤/摘要上下文、恢复情景片段）。策略经监督微调初始化，再用三阶段强化学习课程训练，由局部验证器（评估记忆转移可执行性）和全局验证器（评估证据连贯性与终端记忆一致性）打分，并与任务、证据召回、效率、约束等程序化信号通过分层信用分配相结合；验证器仅训练时使用。在五个基准、两个 LLM 后端上，VerMem 在绝大多数指标上取得最佳结果，并在三个交互基准的受控在线 token 预算下达到最强效率-性能前沿。代码已开源。
核心创新点
  • 统一记忆管理：用一个策略同时控制 LTM、活动上下文与情景历史，而非分开优化长短记忆

解决 LLM Agent 长程交互中记忆管理策略因缺乏细粒度监督而难以学习的问题——传统方法要么长短记忆分开优化，要么仅靠轨迹级反馈导致单个记忆决策（增删检索）得不到有效训练信号。

摘要总结
大型语言模型智能体日益依赖外部工具来完成复杂的真实世界任务，但可靠的工具使用规划仍具挑战性，原因在于隐式推理的局限性和真实执行环境的动态演化。现有工具型智能体通常依赖LLM从文本描述推断工具组合，在复杂任务中可能导致低效探索和不可靠执行。为此，HyperAgent在模式（schema）层面建模工具关系，构建有向的Tool-Schema超图，将工具表示为从所需输入模式节点到输出模式节点的超边，并据此实现动态规划与执行。在AppWorld上的实验表明，HyperAgent在提升任务完成性能的同时，相比现有智能体基线减少了冗余API调用、LLM交互次数和token消耗。
核心创新点
  • 构建Tool-Schema超图，将工具表示为输入模式节点到输出模式节点之间的有向超边，在模式层面显式建模工具间的关系而非依赖文本描述。
  • 任务到达时提取任务相关的工具上下文图，并据此引导构建模式感知的Task DAG，将高层任务分解为模式层面的子任务规划。
  • 执行阶段通过赤字驱动扩展（deficit-oriented expansion）动态构建状态条件化的工具支持图，根据当前智能体状态识别未解决的依赖并检索对应的生产工具。
  • 采用动态规划与执行机制，使工具组合随执行状态实时调整，兼顾规划可靠性与执行效率，在AppWorld上同时改善任务完成率并降低API调用、LLM交互和token开销。
解决的问题 / 适用场景
解决工具型LLM智能体在复杂真实任务中的工具规划与执行不可靠、探索低效的问题，适用于需要动态组合大量API工具完成多步任务（如AppWorld环境中的应用操作类任务）的场景。

摘要总结
视频异常理解（VAU）要求在检测异常事件的基础上，进一步发现支撑证据并解释异常成因。现有方法依赖专门训练或有限观测，泛化能力与证据覆盖受限；单智能体方案虽支持自适应视频观测，但将探索、观测与决策耦合在单一推理流程中，缺乏角色分工与结构化的证据协调。为此提出 AgenticVAU，一个免训练的多智能体框架，将 VAU 建模为「先探索发现潜在异常、再通过定向观测验证」的 explore-verify 流程。在 VAU-Bench 的 ECVA、UCF-Crime、MSAD 子集上，AgenticVAU 优于零样本推理和基于强化学习的基线，验证了多智能体协作对视频异常理解的价值。
核心创新点
  • 提出免训练的多智能体 explore-verify 框架，将异常理解拆分为探索与验证两个阶段，无需专门训练即可适配

  • 引入锚点注册表（anchor registry）作为共享证据记忆，绑定每次观测并驱动智能体间结构化通信

摘要总结
TurnSight 提出一种面向工具集成推理（TIR）的回合级事后自蒸馏框架。针对现有强化学习方法在长程 TIR 中依赖轨迹级监督、信用分配粒度粗糙的问题，TurnSight 直接从执行条件的事后（hindsight）生成监督信号，而非依赖 ground-truth 答案或检索到的技能。它构建多个不同前瞻视野的事后视图，并通过跨视野方向一致性筛选出可靠监督；最后将筛选后的信号在兄弟 rollout 之间归一化，用于自适应调节 RL 优势函数且不改变其原有优化方向。在三个基准上的实验验证了该方法在工具交互式长程推理任务中的有效性。
核心创新点
  • 提出回合级事后自蒸馏：监督信号直接从执行条件的事后视角生成，贴合智能体实际访问的状态，克服了从答案或技能推导上下文与真实轨迹脱节的问题

  • 将事后信号在兄弟 rollout 间归一化，并自适应地调制 RL 优势函数，在保留原始优化方向的同时实现更细粒度的回合级信用分配

摘要总结

核心创新点
  • 将测试时扩展形式化为自回归模型隐式前缀树上的有预算推理，并区分三种结构机制：单轨迹顺序扩展、叶级扩展（终态归约）与前缀级扩展

  • 规定计算量与不确定性的协议匹配报告方式，保证不同研究间结果可对比
  • 明确推理协议的可复现性要求，区分精确重放与分布级可复现性，并指出支撑二者所需的工件；同时按模型侧与接口机制梳理开源推理生态
解决的问题 / 适用场景
解决测试时扩展领域缺乏统一理论框架的问题：不同推理算法被笼统归入单一“预算”标量、评估不附带推理协议，导致跨研究结果无法比较。本文为测试时扩展提供统一的机制分类、评估原则与可复现性规范，使推理系统能够被公平、一致地度量与对比。

摘要总结
统计推理能力是多维的，但现有对大型语言模型（LLM）的评估通常只关注响应准确性，忽视了模型如何构建和传达统计解释。本研究提出了一个多维评估框架，将响应准确性、响应行为、结构化主题建模和词汇相似性分析相结合，对15个当代LLM在跨越高中、本科和研究生水平的90道统计学考题上的解释进行了系统评估。结果表明模型间准确性差异显著（55%至78%），但结构化主题建模显示所有模型在统计推理上共享相似的概念组织，而词汇相似性分析则发现不同厂商（如Anthropic、OpenAI）在解释风格上存在适度但一致的差异——同一厂商的模型之间解释相似度略高于不同厂商。研究发现统计推理不能仅用准确性刻画，行为分析与生成解释的互补分析能提供更全面的评估。

  • 提出结合响应准确性、响应行为、结构化主题建模与词汇相似性分析的多维评估框架，突破单一准确性指标的局限

  • 通过词汇相似性分析定量识别厂商级（如Anthropic、OpenAI）解释风格的系统性差异
  • 构建跨高中、本科、研究生三个层次的90题统计评估基准，覆盖15个当代模型进行大规模横向比较
