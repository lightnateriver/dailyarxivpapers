CoVeR: Coverage-Based Routing of Verifier Calls in Agentic Retrieval
CoVeR：面向智能体检索的基于覆盖度的验证器调用路由
未明确披露（信息不足，原文未列出机构）
点击收起
摘要总结
论文针对智能体检索（agentic retrieval）每一步都要由 LLM 验证器或提示判官判断“已有证据是否足以停止”所导致的重复开销——验证器在每次检索后都要重新处理不断增长的证据——提出 CoVeR（Coverage-based Verifier Routing）：在冻结句向量上取一个覆盖度边际（coverage margin）并设单一阈值，只在证据明显不完整的状态下跳过验证器，仅对模糊的剩余状态发起验证。在三个多跳问答基准上（评测协议在全量运行前即固定），CoVeR 门控智能体的答案准确率与全预算智能体、始终验证（always-verify）基线差距在不到一个 EM 点以内，同时削减 62–68% 的验证器调用，在饱和场景下削减达 93%。基于证据条数、词面重叠或 BM25 的路由器（单独或学习式组合）整体权衡更差，该门控跨不同决策器与 agent 规模无需重调参即可迁移，其 drafter 还能蒸馏为冻结编码器之上 921k 参数的小头，使路由环路中不再含任何 LLM；论文同时强调该信号不能替代验证——判断声称是否被支持远比匹配声称困难。
核心创新点
  • 提出 CoVeR（Coverage-based Verifier Routing）门控：仅在冻结句向量覆盖度边际的单一阈值上判定“证据明显不完整”并跳过验证器，把验证器调用集中到模糊状态，避免每步重复重处理增长证据。
  • 在三个多跳 QA 基准上（评测协议全量运行前固定）以不到 1 个 EM 点的精度损失换得 62–68% 的验证器调用削减，饱和情形下削减 93%。
  • 系统对比证据条数、词面重叠、BM25 及其学习式组合等路由器，证明覆盖度信号在整体 trade-off 上更强，且门控跨决策器与 agent 规模免重调参迁移。
  • 将 drafter 蒸馏为冻结编码器之上仅 921k 参数的头，使路由环路中完全不含 LLM；并指出该信号不能替代验证，划清“匹配声称”与“判定声称被支持”的能力边界。
解决的问题 / 适用场景
适用于需要多步检索并反复判断“何时停下”的检索增强 Agent 生产系统，如多跳问答、知识检索与开放式研究助手：在不牺牲答案准确率的前提下把验证环节的成本与延迟压下来，使长证据链、高并发或成本敏感的 agentic RAG 服务更易落地。

摘要总结

  • 从协态（co-state）敏感度抽取关键推理路径并生成形式化接地的自然语言解释，同时将逻辑不一致率压到接近零并在 CyberSec-Eval 等三个基准上取得 85.4%/95.0%/90.0% 准确率
