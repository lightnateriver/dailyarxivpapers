SBCO: Self-Supervised, Verifier-Grounded Harness Optimization For Planning Agents
SBCO：面向规划 Agent 的自监督、验证器锚定的 Harness 优化方法
未明确披露
点击收起
摘要总结
论文针对自改进 Agent 的通用性问题展开。已有的哥德尔机式方法（如 Darwin/Huxley Gödel Machine）通过让编码 Agent 递归修改自身代码实现开放式自我改进，但这类自参照方法要求任务能力与自我修改能力高度对齐，仅在编码任务中成立。对不满足该对齐条件的领域（如带显式约束的规划任务），现有替代方案要么去掉自参照特性，要么引入元 Agent 显式自修改，两者都依赖大量候选 Agent 的群体搜索或自修改搜索，计算开销高昂。为此论文提出 SBCO（Self-supervised Block Coordinate Optimizer，自监督块坐标优化器）：它属于与哥德尔机方法同一族“闭环、从经验中改进”的框架，但采用自监督而非自参照。SBCO 在固定元 Agent、无人工标注的条件下，学习一组分解的验证器库（bank of verifiers）与 harness 策略，通过近似块坐标上升从 Agent 自身的分级反馈中改进输出。在两个领域的实验中，SBCO 以 4-5.5 倍更少的计算预算达到或超过了定制化自修改基线的表现。
核心创新点
  • 提出 SBCO 自监督块坐标优化框架：将哥德尔机式闭环自我改进思想推广到不满足自参照对齐条件的任务（带显式约束的规划），无需自引用或元 Agent 显式自修改，避开高开销的群体/自修改搜索。
  • 设计分解式验证器库（decomposed bank of verifiers）与 harness 策略的联合学习：通过近似块坐标上升（block coordinate ascent）在固定元 Agent 下从自身分级反馈中迭代优化 Agent 行为，全程无人工标签。
  • 计算效率显著：在两个领域上以 4-5.5 倍更少的计算预算达到或超越定制化自修改基线，证明自监督 harness 优化是自参照方法更廉价的替代路径。
解决的问题 / 适用场景
适用于带显式约束的规划类 Agent 场景，尤其是任务能力与代码自我修改能力不对齐、无法直接套用自参照式自我改进的领域；典型应用包括在不引入额外人力标注的前提下，让规划 Agent 借助可验证的约束与反馈闭环持续优化自身决策策略，例如约束满足规划、任务编排等。

GeoForge: Non-Parametric Self-Evolving Agents for Earth-Observation Reasoning
GeoForge：面向对地观测推理的非参数自进化智能体
未明确披露
点击收起
摘要总结
对地观测（EO）智能体需要构建科学有效的工具工作流，并基于当前地理空间证据得出结论，但 EO 工作流受传感语义、产品依赖、时空兼容性和参数要求的多重约束，难度很高。现有智能体往往为每个查询在广阔的操作空间中盲目搜索，而近期的自进化系统也未能把异构的 EO 轨迹组织成跨决策层级可复用的知识。GeoForge 提出一种免训练的自进化框架，将已完成轨迹转化为结构化的非参数执行状态：先按传感上下文约束操作空间，再从三种互补记忆中检索任务条件先验——工作流图记忆（Workflow Graph Memory）捕获全局操作顺序、动作级经验（Action-Level Experiences）提供局部修正、适配技能标准操作程序（Adapted Skill SOP）保留程序与数据约束；检索到的先验引导工具执行，最终答案仍以当前观测为依据。每项任务结束后，经过安全门控（safety-gated）的蒸馏过程把基于事实的轨迹沉淀为可复用执行知识，供后续检索。这个执行—蒸馏—复用闭环在不更新主干 LLM 的前提下持续提升规划能力。在多个地理空间基准上的实验显示，GeoForge 在多种 LLM 主干上同时提升任务准确率与工具使用轨迹质量，并显著减少多数 LLM 的工具规划与推理错误。
核心创新点
  • 免训练自进化范式：不更新主干 LLM，仅靠执行—蒸馏—复用闭环持续改进规划，训练成本为零
  • 非参数执行状态：把完成任务轨迹转化为结构化、可检索的执行知识，实现跨查询、跨决策层级的复用
  • 三重互补记忆设计：工作流图记忆负责全局操作顺序，动作级经验提供局部修正，适配技能 SOP 固化程序与数据约束，分工明确
  • 安全门控蒸馏：过滤不可靠轨迹，只把基于事实的验证结果沉淀为知识，防止错误经验回流
  • 传感上下文感知的操作空间约束：先缩小搜索范围再检索先验，降低工具规划与推理错误率
解决的问题 / 适用场景
对地观测与地理空间分析中的科学工作流自动构建，如环境监测、灾害响应评估、土地利用与植被变化分析等需要跨多源卫星数据、产品依赖链和时空一致性约束编排工具的智能体应用，也适用于接入遥感/GIS 数据与工具 API 的通用 Agent 推理系统。

摘要总结
本文研究如何从开发者与编码智能体的长期交互历史中提炼可复用的个性化技能，以适配个体开发者的偏好、减少重复纠正。作者提出一个框架：先通过基于规则的自举和证据支撑的细化生成个性化技能，再利用可复现的重放评估框架（含交互式、轨迹条件化的 LLM 人类开发者模拟器）评测其效果。在来自 13 位开发者的 206 个真实开发者-智能体会话上，与无技能、通用技能、他人技能等基线对比发现：个性化技能相比无技能基线提升很小且不稳定，而跨开发者汇聚的通用技能收益最大且最一致；仅当开发者偏好频繁出现、且历史中包含多个与未来任务相关的示例时，个性化才更有效。

摘要总结
大型推理模型（LRM）通过增加推理时算力生成更长的思维链来提升性能，但近期研究表明纯顺序式测试时扩展往往收益递减甚至为负：更长的推理轨迹伴随更高的不确定性、错误累积以及偏离原题的问题。ThinkRetrieve 提出一种测试时扩展框架，在 LRM 推理的每一步动态检索已解决的示例，并将其直接注入思维轨迹，为模型提供"如何推理"的引导，而非仅仅告诉它"哪些事实相关"。在 GSM-8K、MATH-500、AIME 2025 和 SciQ 上，对五个 1.5B–8B 参数的推理模型，ThinkRetrieve 相比标准测试时扩展持续提升准确率，在 AIME 2025 上相对增益最高达 60%。

摘要总结
