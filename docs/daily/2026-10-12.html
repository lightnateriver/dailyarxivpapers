摘要总结
本文检验在线策略自蒸馏（on-policy self-distillation）所依赖的打分信号是否真的包含纠错信用：作者用学生 rollout 中的标注错误区间作为金标准，测试自蒸馏目标消耗的两种信号——全分布 KL 与 token 对数比——能否定位错误、能否把概率推离错误的 token，结果二者都不具备这两种性质，也无法在同一问题内可靠区分正确与错误的 rollout。作者认为这种失败是结构性的：在推理轨迹中定位错误本身是一个搜索问题，而只负责打分的教师从未被明确要求去做这个搜索；同一模型在拥有同样特权信息时，一旦被允许生成批判（critique），错误定位能力显著提升。据此提出批判条件化自蒸馏（critique-conditioned self-distillation）：先生成对当前 rollout 的批判，再让打分教师以该批判为条件，得到的信号能够定位错误、在错误区间内具有纠正性，并把概率推向 "Wait"、"But"、"Actually" 等触发回溯的 token；该批判在测试时可让模型接续错误 rollout 并解出采样无法解决的数学题，在冷启动 GRPO 中还能为可验证奖励无法提供优势信号的 prompt 给出优势信号。
核心创新点
  • 用 gold error spans 定量拆解在线策略自蒸馏的两种信号（全分布 KL 与 token 对数比），实证证明二者既不能定位错误也不能把概率推离错误 token，也无法在同一问题内区分正确/错误 rollout。
  • 提出结构性解释：推理轨迹中的错误定位本质是搜索问题，而仅打分的教师未被要求执行该搜索；并用同一模型同一特权信息的对比实验，证明允许生成批判后错误定位显著变好。
  • 设计 critique-conditioned self-distillation 流程：先对当前 rollout 生成批判，再把打分教师条件化于该批判，使蒸馏信号在错误区间具备纠正性，并显著提高 "Wait"/"But"/"Actually" 等回溯触发 token 的概率。
  • 将批判扩展到两个下游用途：测试时用批判在上下文中续写错误 rollout，解出采样无法解决的数学题；冷启动 GRPO 中用批判为可验证奖励无信号可用的 prompt 提供优势信号。
解决的问题 / 适用场景

摘要总结
在线策略蒸馏（OPD）在 VLM 后训练中能由教师给学生提供密集监督，但作者观察到一个异常现象：被蒸馏的 VLM 即使相关视觉区域被遮蔽或替换成噪声，仍能准确作答。基于这一现象，定量与定性实验表明，以答案为提示的 OPD 并未真正教会学生主动寻找并依赖视觉证据；理论分析将这一失败归因于蒸馏过程中缺乏视觉约束所打开的“捷径”。为此提出 CV-OPD（Contrastive Vision On-policy Distillation）：在相同学生前缀条件下，对比正、负裁剪所诱导的教师分布，并引入基于 margin 的对比约束，再用 token 级与样本级差异门控加以调制。具体地，CV-OPD 先引入一个与答案无关的负教师，设计对比散度损失（CDL），通过对比正/负教师来约束学生特征分布，纠正学生对视觉区域的利用方式；同时引入差异感知门（DAG），利用 token 级和样本级差异筛选出与视觉相关的 token 参与优化，把学生注意力导向视觉内容。大量细粒度视觉基准上的实验表明，CV-OPD 显著缓解捷径问题，并持续提升现有 VLM 的视觉推理能力。
核心创新点
  • 1）发现并量化 OPD 的“捷径”失效模式：遮蔽或噪声替换视觉区域后蒸馏模型仍能答对，说明其未真正依赖视觉证据；2）给出理论分析，指出蒸馏中缺少视觉约束是捷径产生的根源；3）提出 CV-OPD，引入与答案无关的负教师，并用对比散度损失 CDL 对比正负教师分布以约束学生特征、纠正其视觉区域利用方式；4）提出差异感知门 DAG，以 token 级与样本级差异挑选视觉相关 token 进行优化，配合 margin 对比约束与差异门控，将学生注意力引向视觉内容。

适用于 VLM 的后训练与知识蒸馏场景，尤其是图文理解、细粒度视觉推理等需要学生模型真正依据图像证据作答的任务；可缓解模型依赖文本先验或答案提示的捷径行为与视觉幻觉，提升视觉 grounding 与细粒度视觉推理表现。
