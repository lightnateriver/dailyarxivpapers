针对少步自回归视频生成器对所有 token 一律跑完最终去噪步、无视其实际精修需求的均匀计算浪费，论文观察到不少 token 在最初几步就已接近全步输出、另一些则需精修到底，于是提出 Speculative Forcing：把去噪过程中的中间干净估计当作草稿，逐 token 预测何时可以被安全提前接受，一旦接受即冻结为最终输出、不再参与后续去噪，但其缓存的 key/value 仍作为上下文供剩余 token 使用。作者给出两种验证器设计——基于与干净内容相似度及跨步稳定性的免训练版本，以及读取冻结生成器中间特征来估计该 token 距全步输出残余差距的可学习版本。在短视频、长视频与世界生成任务上，该方法在保持全步采样质量的同时大幅降低计算：LongLive 上以约 1.7 步去噪/token 匹配四步生成器，41.7 与 37.8 fps 下提速超过 1.5×；在镜头运动持续改变可见内容的 Lingbot-World 2.0 上以约 2.5 步/token 维持质量，24.5 fps 下提速 1.35×。
核心创新点
  • Speculative Forcing 框架：将中间干净估计视为草稿，逐 token 预测能否提前接受并冻结为最终输出，从而跳过对该 token 无意义的后续去噪步
  • 提前冻结的 token 虽不再去噪，其缓存 KV 仍作为上下文参与后续 token 生成，保证自回归流式生成的连贯性
  • 两种验证器设计：免训练的相似度+跨步稳定性判据，以及读取冻结生成器中间特征、估计 token 与全步输出残余差距的学习型验证器
  • 在 LongLive 上以 ~1.7 去噪步/token 对齐四步生成器质量、提速 >1.5×（41.7/37.8 fps），在 Lingbot-World 2.0 上以 ~2.5 步/token、24.5 fps 提速 1.35×，覆盖短视频、长视频与世界生成三类任务
解决的问题 / 适用场景
面向流式/实时自回归视频生成的推理加速：适用于 LongLive 这类长视频生成服务与相机可控、内容持续变化的交互式世界模型（Lingbot-World 2.0），在保证画质的前提下降低单位 token 去噪开销，改善实时帧率与端到端时延。
