摘要总结
论文指出 MoE 专家剪枝虽能缓解专家必须常驻加速器带来的显存部署瓶颈，但现有方法都是静态的——离线校准一次得到的固定掩码对之后所有请求生效，这在多智能体系统这类异构负载下会失效，因为不同任务与角色会调用不同专家。为此提出 Dynamic Expert Pruning (DEP)，基于论文确立的关键发现：智能体的 system prompt 与 task prompt 本身已足以识别该智能体及其任务所需专家，因为文本已描述智能体将要做什么。一个仅在工作流轨迹上训练一次的轻量预测器，即可把 prompt 在单次前向中映射为每请求专属掩码，无需按配置校准；在多种任务/角色、模型规模与 MoE 架构上，DEP 整体精度优于静态剪枝与专家合并基线，并能泛化到训练中未见的工作流，在最稀疏保留专家时优势最大。
核心创新点
  • 提出 Dynamic Expert Pruning (DEP)：由轻量预测器将每请求的 system/task prompt 在单次前向中映射为专属专家掩码，免除按配置的离线校准

解决的问题 / 适用场景
适用于单一骨干模型同时承载多任务、多角色的多智能体推理服务，用于降低 MoE 模型的显存常驻需求、提升部署密度与成本效率。

摘要总结
未来无线网络要求学习智能体跨异构信道、流量模式、QoS 需求与运营约束适配，而现有多任务与迁移强化学习主要在策略空间共享知识，使可迁移知识与任务相关的动作映射相互耦合。本文提出 FARM，将跨任务知识复用从策略空间转移到轨迹级决策评估，即奖励空间迁移，其核心 Agentic Reward Model（ARM）从异构源任务轨迹中学习任务条件化的奖励先验并为任务特定策略优化提供辅助指导。第一阶段 ARM 联合建模任务条件、时序轨迹依赖与目标相关奖励结构且各源任务保留自身控制器，第二阶段冻结奖励先验、在不迁移源任务策略的前提下引导未见任务的目标控制器适配。在异构多接入边缘计算（MEC）任务上，FARM 在未见的 Rate-Latency 目标上相对 Single-task SAC 取得 29.8% 的后期增益（CRA Transfer 为 16.1%），在中等 OOD 的 FAR-M 场景增益达 46.2%。
核心创新点
  • 提出 FARM 奖励空间迁移框架，把跨任务知识复用从策略空间转移到轨迹级决策评估，避免可迁移知识与任务相关动作映射耦合。

  • 设计两阶段流程：Stage I 各源任务保留独立控制器、ARM 学习奖励先验；Stage II 冻结奖励先验并复用其引导目标任务控制器适配，不迁移任何源任务策略。
  • 在异构 MEC 任务上验证：未见的 Rate-Latency 目标取得 29.8% 后期增益（对比 CRA Transfer 的 16.1%），中等 OOD 的 FAR-M 增益 46.2%；并发现 Mamba 与 Transformer 轨迹编码器均支持奖励空间迁移，Mamba 在更长历史依赖下鲁棒性更好。

摘要总结
论文指出语言模型智能体总是带着harness（管理上下文、工具与反馈的外围软件）部署，而将智能体蒸馏为更小模型时harness保持不变，学生主要只需学习harness无法提供的教师特有能力，例如正确地对harness信息作出动作。作者提出Harness-Aware Distillation（HAD），在在线策略蒸馏（on-policy distillation）基础上加入两个组件：动作偏好（对比同一教师在有/无harness信息下的动作，并在学生自身推理之后打分）与有效性校验（剔除偏好动作与harness记录相矛盾的偏好对）。HAD不需要任务奖励、成功标签或未来信息，在多个长程智能体基准与模型上优于相同固定harness下的在线策略蒸馏基线。分析显示HAD更少陷入无效循环、更常从错误中恢复，并倾向于把可学习反馈保留在权重中、从harness读取状态信息。
核心创新点
  • 提出Harness-Aware Distillation（HAD），把蒸馏目标从模仿教师全部输出转向只学习教师超越harness的部分，并保留固定harness不变的前提。
  • 设计动作偏好机制：对比同一教师在有/无harness信息下给出的动作，且在学生自身推理之后打分，从而提供单纯模仿教师无法获得的信息。
  • 引入有效性校验，自动剔除偏好动作与harness记录相矛盾的偏好对，保证偏好信号一致性。
  • 方法无需任务奖励、成功标签与未来信息；实验分析显示HAD更少进入无效循环、更常从错误恢复，并能自适应地把可学习反馈留在权重中、从harness读取状态信息。
解决的问题 / 适用场景
面向把强教师智能体教师蒸馏/压缩成小语言模型智能体的落地场景，适用于带有工具调用、上下文管理与反馈环的智能体系统（如长程任务型Agent）在固定harness下做能力对齐与模型小型化。

Learning from Repaired Reasoning: Root-Cause-Guided On-Policy Distillation
从被修复的推理中学习：根因引导的在线策略蒸馏
未明确披露
点击收起
摘要总结
论文针对在线策略自蒸馏（OPSD）依赖参考解作为特权hindsight的问题：参考指导可能解释了正确解却没有说明学生自身推理为何失败，这种“指导与所需纠正不匹配”会让学生借用正确结论却保留推理错误；同时全程施加同一hindsight会带来“蒸馏陷阱”，使对有效推理的多余约束与对实质性错误的纠正相互竞争。作者提出Root-Cause-Guided On-Policy Distillation（RC-OPD）：对每次失败定位最早的实质性错误并生成局部修正，用修正后的中间结果作为有效前缀的锚点，并通过“诊断—修复—续写”迭代流程在固定修复预算内测试修复并发现后续错误。对到达正确答案的修复链，根因引导蒸馏用失败诊断与纠正目标监督错误片段，锚点引导蒸馏则用通向已修复中间结果的推理链支撑对应的有效前缀。在多个数据集与模型规模上的实验表明，RC-OPD缓解了推理不匹配与蒸馏陷阱，带来显著性能提升。
核心创新点
  • 提出RC-OPD，用学生自身推理的“修复”而非参考解提供指导，使指导直接针对学生的具体错误，同时建立在其有效进展之上。
  • 设计“诊断—修复—续写”迭代流程：每次失败定位最早实质性错误、生成局部修正、以修正后的中间结果作为有效前缀锚点，并在固定修复预算内通过学生续写继续发现后续错误。
  • 在修复链可达正确答案时组合两种监督：根因引导蒸馏用失败诊断与纠正目标监督错误片段，锚点引导蒸馏用推理链支撑对应的有效前缀。
  • 在多个数据集与模型规模上验证，缓解reasoning mismatch与distillation trap，取得显著性能增益。
解决的问题 / 适用场景
适用于学生模型从大模型蒸馏复杂推理能力的场景，尤其是需要纠正学生自身推理错误的长链推理任务（数学、逻辑与智能体推理系统）的模型小型化与能力对齐。
