CompoSkill: Compositional Skill Chain Attacks from Individually Scanner-Passing LLM Agent Skills
CompoSkill：利用单个均通过扫描的 LLM Agent 技能构造组合式技能链攻击
未明确披露
点击收起
摘要总结
自主 AI Agent 执行长程任务时依赖市场上逐份认证的技能包：扫描器对每个技能单独给出安全判定，若全部通过即认定生态安全。本文证明该假设在技能组合场景下不成立——单个技能可能各自通过扫描，但当 Agent 将多个技能的输出、能力或副作用串联起来时，却可能构成危险组合。技能组合风险因此是路径级而非节点级属性，这也解释了现有逐包检查的技能扫描器为何拦截效果有限。为系统研究该威胁，作者提出 CompoSkill 框架，采用双攻击者体系：白盒攻击者知晓受害者已安装的技能池，直接注入显式技能 ID 序列；黑盒攻击者仅知道角色画像，自动下载该场景下的市场热门技能，构建技能组合图（Skill Composition Graph）并搜索隐式诱饵、从不点名技能标识符的高风险链路。作者还构建了 CompoSkill-Bench 基准，包含 1,140 条记录，覆盖 OpenClaw 与 Nanobot 上五种威胁、六个场景的长程专业工作流。实验显示，CompoSkill 在白盒设定下风险链路形成率（CFR）最高达 83.3%，黑盒设定下达 80.6%，而现有技能扫描器仅能拦截有限比例的危险组合。此外观察到 bridge-bonus-then-hop-decay 规律：桥梁技能可提升攻击成功率，但风险链超过三个技能后，额外跳数会使攻击成功率（ASR）下降。这些结果系统性暴露了自主 AI Agent 单技能认证体系的安全缺口。
核心创新点
  • 提出“技能组合攻击”新威胁模型，论证组合风险是路径级而非节点级属性，从根因上解释了逐包技能扫描器拦截率低的现象
  • 设计 CompoSkill 双攻击者框架：白盒攻击者注入显式技能 ID 序列，黑盒攻击者仅凭角色画像自动抓取热门技能、构建技能组合图并挖掘隐式高风险链路
  • 发布 CompoSkill-Bench 基准：1,140 条记录、五种威胁、六个场景，覆盖 OpenClaw 与 Nanobot 两大 Agent 生态
  • 发现 bridge-bonus-then-hop-decay 模式：桥梁技能放大攻击效果，但风险链超过三跳后 ASR 随跳数衰减，刻画了技能链长度的风险边界
解决的问题 / 适用场景
适用于 LLM Agent 生态安全治理：技能市场（OpenClaw、Nanobot 类平台）的准入与组合级审查、Agent 运行时对技能链路的实时风险监控，以及将单技能认证升级为链路级认证；亦可作为红队测试工具，评估自主 Agent 在长程专业任务中的组合攻击暴露面。

核心创新点
  • 提出 Latent-OPD：在输出级 OPD 之上叠加轨迹级潜在蒸馏，直接约束推理过程中的隐状态表征，而非仅匹配输出 token 分布
  • 聚焦轨迹末尾位置的隐状态进行蒸馏——该位置能汇总跨帧累积的视觉证据与推理上下文，契合视频推理的证据聚合特性
  • 引入渐进式教师前瞻策略，将学生中后段层与教师逐层加深的层对齐，实现层级化的知识迁移
解决的问题 / 适用场景
视频推理模型压缩与蒸馏：在帧数有限、长视频或需复杂证据聚合的计算受限场景下，将大模型推理能力迁移到小模型，可服务于视频问答、多模态推理加速、端侧视频理解等对算力敏感的部署场景。
