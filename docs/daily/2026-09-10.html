他们彼此是什么关系？用于说话人关系推断的多智能体推理
未明确披露
点击收起
摘要总结
论文针对口语对话中说话人关系推断这一研究不足的任务，指出现有推理期 LLM 方案缺乏结构来处理细微、分散且多模态的关系线索，而监督建模又训练成本高、难扩展，因此提出一个免训练的多智能体推理框架，让 LLM 智能体通过结构化交互提出、质疑并裁决关系判断。框架有两种实例化：Multi-Role Multi-Agent Debate 把标准多智能体辩论改造为角色互补或带有社会理论视角的多角色辩论；Multi-Agent Compete 则用成对裁决（pairwise adjudication）比较各智能体判断、淘汰较弱候选并保留最有辩护力的结论。作者在 Seamless Interaction 数据集上覆盖不同模态设置，评测二分类与细粒度关系细节预测，结果显示多数情况下优于零样本和现有多智能体基线；人工评测表明该任务对人类本身也很难，LLM 在含文本设置下有时能超过人类标注者，但在纯音频设置下竞争力明显下降。
核心创新点
  • 提出免训练的多智能体推理框架，把说话人关系推断组织为智能体之间的提出-质疑-裁决流程，无需任务特定训练即可扩展。
  • Multi-Role Multi-Agent Debate：将标准多智能体辩论改造为角色互补或社会理论视角驱动的多角色辩论，而非单一同质视角投票。
  • Multi-Agent Compete：一种基于竞争的协议，通过成对裁决比较智能体判断、淘汰较弱候选、保留最具辩护力的结果。
  • 在 Seamless Interaction 数据集上跨模态设置评测二分类与细粒度关系预测，并配合人工评测揭示 LLM 在含文本条件下可超过人类标注者、但在纯音频条件下明显落后，说明声学线索尚未被现有模型充分捕捉。
解决的问题 / 适用场景
用于从真实对话语音中自动推断说话人之间的关系（如亲属、同事、上下级等），可服务于会议记录理解、客服质检、社交与陪伴类语音助手、以及需要“社交感知”的语音理解与检索系统，帮助在缺少人工标注训练数据时以推理期多智能体协作替代监督训练。

  • 公开代码与数据集，使可执行城市规划这一真实空间优化任务具备可复现的评测平台。
解决的问题 / 适用场景
适用于需要从大规模候选动作中给出可落地空间配置的城市规划与公共设施布局决策场景，例如土地用途分配、服务设施选址等，可运行在需要“方案生成—指标评估—反馈改进”闭环的规划辅助系统中，替代难以迁移的任务专属优化器。

TRACE：用合成奖励训练因果探索推理智能体
未明确披露
点击收起
摘要总结
论文针对可验证奖励强化学习（RLVR）在复杂数据诊断推理中的失效问题：数学与代码有廉价可验证的客观答案，而定位异常真正成因需要昂贵的专家调查且事后往往仍有歧义。作者提出对这一“验证不对称性”进行工程化改造——采样一个干预并注入受控模拟器，生成该干预本应产生的观测，隐藏的干预天然提供 oracle 标签与客观奖励，而智能体仍须在噪声、混杂与分布式证据中自行调查。该方法在 TRACE 数字广告诊断环境中实例化，包含 12 类根因和细粒度细分人群归因，智能体需用 Python 与 SQL 调查每个 episode 并同时给出根因与受影响人群归属。在 235 条留出测试集上，最强提示基线 Claude Opus 5 取得 0.686 FullAttr@1，监督微调把 Qwen3.5-35B-A3B 从 0.159 提升到 0.637，再用合成奖励做 RL 达到 0.757，超过包括前沿闭源模型和提示版 Qwen3.5-122B-A10B 在内的所有提示基线，且工具调用次数显著少于提示版 35B 基线。
核心创新点
  • 提出基于模拟器注入干预的合成奖励机制：隐藏干预充当 oracle 标签，直接为诊断推理提供规模化、客观的 RLVR 训练信号，绕开昂贵且模糊的专家验证环节。
  • 构建 TRACE 数字广告诊断环境，含 12 类根因与细粒度细分人群归因，智能体必须以 Python/SQL 多轮工具调用同时完成根因识别与受影响人群归属判定。
  • 提出 FullAttr@1 这一同时考核根因与人群归属正确性的复合评测指标，并在 235 条留出 episode 测试集上完成基线对照。
  • 实证发现“训练信号可获得性”比模型规模更关键：SFT+RL 的 Qwen3.5-35B-A3B（0.757）反超规模更大乃至闭源的前沿提示模型，同时工具调用更少。
解决的问题 / 适用场景
面向复杂业务数据的根因诊断场景，例如广告投放效果异常归因、线上指标波动排查等，可部署为以 SQL/Python 自主调查数据仓库的诊断智能体；为缺少廉价验证标签的领域提供了一条用仿真器批量造训练奖励、从而训练诊断推理策略的可行路径。

VLX-VR：一种具备智能体意识的视频推理模型
未明确披露
点击收起
摘要总结
针对现有视频理解流水线使用固定视频上下文、单次推理，在观测不完整、歧义或冲突时无法自适应补充证据的问题，论文提出 VLX-VR，在 Think–Memory–Observation 循环定义的推理框架内训练。模型每一步自行判断所需证据，调用 read_memory 或 write_memory 并吸收返回的 Observation，再决定继续推理还是输出任务结果；训练数据同时包含视频与智能体交互轨迹，并用强化学习学习取证、记忆使用与终止策略。在 MINERVA 上，VLX-VR 取得对比模型中最优的 78.79% 准确率，三个时长分组分别为 76.70%、78.73%、80.92%，跨时长方差仅 2.97 pp²。在答对的样本中，96.20% 的推理轨迹与 MINERVA 参考推理轨迹及其描述的证据一致，全部评测样本中约 75.80% 同时满足答案正确与该证据可依条件。
核心创新点
  • 提出 Think–Memory–Observation 三阶段智能体推理循环：模型逐步判定缺失证据，自主调用 read_memory / write_memory 工具获取或写入信息，并据此决定是否终止推理，突破了固定上下文单次前向的限制。
  • 使用同时包含真实视频与智能体交互轨迹的多模态数据进行强化学习训练，使模型同时学会证据获取、记忆读写与终止决策三类策略，而非仅拟合最终答案。
  • 在 MINERVA 视频推理基准上取得对比范围内最优 78.79% 准确率，且 76.70% / 78.73% / 80.92% 的三时长分组结果对应仅 2.97 pp² 的跨时长方差，显示长视频下行为稳定。
  • 引入证据落地的轨迹评估：正确回答样本中 96.20% 的推理轨迹与 MINERVA 参考链及其中描述的证据一致，全体样本约 75.80% 同时满足答案正确与证据一致，并明确指出计数、状态变化、因果推理和空间感知仍是难点。
解决的问题 / 适用场景
适用于视频问答与长视频内容理解系统，例如监控录像事件检索、赛事或教学视频问答、多模态内容审核与检索增强的视频助手；当单帧或单次观测不足以回答、且信息存在歧义冲突时，系统可主动多次取回证据再作答。

摘要总结
论文指出广告视频生成不仅是视频合成任务，更是以线上业务指标为成功标准的、由商品条件驱动的推理问题，而现有视频基础模型既不优化“商品如何转化为有效广告”，也不利用线上业务反馈改进后续生成。为此提出 AgenticGen，把广告视频生成拆成策略选择与草稿生成两个可训练推理阶段，从而暴露可被线上反馈监督的优化目标。方法从累积线上反馈中学习基于表现的奖励，并辅以对齐人类质量标准的评分表奖励作为补充，监督策略优化：先用 DPO 将两个阶段的策略推向线上偏好，再用 GRPO 结合过程奖励与结果奖励精调。离线实验验证了奖励模型与逐级策略优化，TikTok 广告系统线上 A/B 实验显示，经 DPO 与 GRPO 后相较 SFT 基线 CTR 提升 2.72%、CVR 提升 2.63%、Advv 提升 9.61%。
核心创新点
  • 将广告视频生成重构为“策略选择 + 草稿生成”两阶段可训练智能体策略，使原本只在最终成片上体现的线上业务反馈能够直接监督中间推理环节，形成从投放反馈到生成的闭环。
  • 设计双奖励体系：从累积线上反馈中学习基于表现（performance-based）的奖励，并引入与人类质量标准对齐的评分表（rubric-based）奖励，兼顾业务效果与内容质量。
  • 提出 DPO 与 GRPO 递进式优化流程：DPO 先把两阶段策略对齐到线上偏好，GRPO 再以过程奖励与结果奖励联合精调两个阶段，实现分阶段、可验证的策略改进。
  • 在 TikTok 广告系统完成线上 A/B 验证，DPO+GRPO 相比 SFT 基线将 CTR 提升 2.72%、CVR 提升 2.63%、Advv 提升 9.61%，给出了生成模型直接优化商业指标的实证结果。
解决的问题 / 适用场景
面向广告素材自动化生产与投放优化：适用于短视频/信息流广告平台的商品推广视频生成系统，用真实投放的点击、转化与广告观看指标反向指导生成策略迭代，帮助广告主以更低成本产出更有效的商品广告。

摘要总结
隐式推理用紧凑的连续空间嵌入替代冗长的显式思维链（CoT）token 以提升 token 效率与鲁棒性，但现有方法缺乏对这些隐层嵌入的直接过程监督，容易造成表示崩塌与信息分布不均。论文提出原型介导的过程监督（Prototype-Mediated Process Supervision, PMPS），引入可学习的推理原型作为语义锚点，将隐式嵌入与显式 CoT 嵌入投影到共享原型空间，通过原型分配实现不等长表示之间的多对多软对齐；并设计渐进式序列对齐（Progressive Sequential Alignment, PSA）模块，先用位置先验鼓励序列对齐结构，再逐步放松以允许自适应匹配。在 GSM8K-Aug 上 PMPS 将输出 token 长度压缩到显式 CoT 的 50% 以下，相比最强基线 SIM-CoT 在不同模型族上平均准确率提升 2.08%；在 GPT-2 上甚至超过 CoT-SFT，并在更大模型与更难任务上以相近输出长度取得所有隐式推理方法中的最高准确率。
