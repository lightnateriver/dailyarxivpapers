摘要总结
论文针对代理代表他人执行购买服务、交换信息、委派任务时，仅靠指令、策略或协议文本无法保证其真正遵守约定这一问题，提出 Proof-Carrying Contracts（PC2）框架：任何被请求的操作在执行前，代理必须提交一份机器可检查的证明，论证在其自身模型的每一种可能情形下都保持双方约定的约束，再由名为 Airlock 的执行系统校验证明并据此控制对该操作的访问。作者证明即使代理是恶意的，约束在执行过程的每一时刻都成立，并刻画了该性质可推出真实世界安全性的条件；同时提供可复用的 capability 模块作为构造合约的工具与保证。
核心创新点
  • 提出 PC2 框架，把「约束始终成立」转化为代理必须随请求提交的机器可检查证明，从而无需为每条被允许的决策单独设计权限策略并逐一证明其安全
  • 设计 Airlock 执行系统，将证明检查与操作访问控制绑定，在操作真正运行前完成放行判定
  • 给出针对对抗性代理的形式化保证：约束在执行全过程中每一时刻均成立，并明确该保证转化为现实世界安全性的前提条件

核心创新点
  • 提出“通用编码智能体 + 命令行 3D 感知工具箱”的耦合方案，不改模型权重、不做任务微调，仅通过 CLI 接口让视觉语言模型主动取证，且所有读数保持几何可溯源。
  • 设计持久化场景记忆（persistent scene memory），让已采集证据跨多轮工具调用留存复用，避免长工具链中重复取证和上下文丢失。
  • 确立“用平实空间语言解释每个读数”的接口原则，把工具原始输出直接转成模型可消费的空间结论，专门针对工具正确但模型仍答错的证据回路断裂问题。
  • 发现工具增益随骨干能力增强而收窄，但在 ReVSI 上 SpatialClaw 的增益从 +13.2 骤降到 +2.7，而该方法仍保持 +9.6，说明其设计对强模型更抗饱和；并验证可跨 Codex、Claude Code 等不同编码智能体框架迁移。
解决的问题 / 适用场景
面向需要三维空间理解与可核查几何依据的下游系统，例如具身智能与机器人在场景中的物体定位和关系判断、AR/VR 场景问答、以及多模态助手对空间问题的证据化回答；可直接挂在现有编码智能体框架上使用，无需重训模型。
